# 電流、電壓與負荷電力

在連接加熱器、風扇、LED燈帶、伺服驅動器或其他模組之前，您需要理解三件事：

- 電壓；
- 電流；
- 電力。

如果沒有這個，很容易購買錯誤的電源、過熱電線、熔化連接器、燒毀MOSFET模組或將負荷連接到控制器，使其不穩定工作。

## 參數在哪裡找

電壓、電流和電力通常可在以下位置找到：

- 元件外殼上；
- 電源標籤上；
- 產品頁面上；
- 技術規格中；
- 手冊中；
- 電路圖或引腳排列圖中。

如果未指定參數，這不是小問題。這是停下來弄清楚您要連接什麼的理由。

對於3D打印機外設中的元件，典型的參數如下：

- 風扇：`24V 0.2A`；
- 加熱器：`24V 100W`；
- LED燈帶：`24V 9.6W/m`；
- 伺服驅動器：`5V`，電流取決於負荷；
- 控制器板：每個輸出的最大電流單獨指定。

## 電壓必須匹配

負荷是為特定電壓設計的。

例子：

- 風扇可以是`5V`、`12V`或`24V`；
- LED燈帶可以是`5V`、`12V`或`24V`；
- 伺服驅動器通常額定為`5V`或`6V`；
- 加熱器可以是`12V`、`24V`或`110-230V AC`。

如果您將`24V`風扇連接到`12V`，它可能無法啟動或工作不力。如果您將`12V`風扇連接到`24V`，它可能很快失效。

主要規則：

**電源電壓必須與負荷電壓匹配。**

不要僅因為連接器在物理上適配就將設備連接到更高電壓。

## 電力顯示負荷大小

電力顯示負荷消耗或轉化為工作、熱、光或運動的能量。

電力以瓦特測量：`W`。

例子：

- `24V 5W` - 小負荷；
- `24V 24W` - 約`1A`；
- `24V 120W` - 已約`5A`；
- `24V 240W` - 約`10A`。

加熱器通常消耗大量電力。風扇消耗較少，但可能有高浪涌電流。LED燈帶如果很短可能是小負荷，或者如果很長且很亮可能是重負荷。

## 電流對電線和電源元件加載

電流顯示流過電線、端子、連接器和電源元件的電量。

電流經常造成實際問題：

- 電線發熱；
- 端子變暗；
- 連接器熔化；
- MOSFET過熱；
- 電源不足；
- 負荷打開時設備重新啟動；
- 保險絲熔斷不是巧合，而是由於實際過載或錯誤。

因此，僅知道電壓是不夠的。您需要計算電流。

## 計算公式

對於大多數簡單計算，您需要電力公式：

```text
P = U * I
```

其中：

- `P` - 瓦特電力`W`；
- `U` - 伏特電壓`V`；
- `I` - 安培電流`A`。

要找到電流：

```text
I = P / U
```

此公式不是為了考試。需要理解電源、電線、端子、MOSFET模組、繼電器、SSR或電路板輸出是否能承受它。

## 24V的快速表

在3D打印機和外設中，`24V`很常見。為了快速評估，記住以下有用：

| 電力 | 24V時的電流 |
|---:|---:|
| `12W` | `0.5A` |
| `24W` | `1A` |
| `48W` | `2A` |
| `96W` | `4A` |
| `120W` | `5A` |
| `240W` | `10A` |
| `300W` | `12.5A` |

這些是近似值，但對於電源、電線和電源開關的首次選擇非常有用。

## 示例：24V 100W加熱器

您有一個加熱器：

```text
24V 100W
```

計算電流：

```text
I = 100W / 24V = 4.17A
```

這意味著以下必須能承受超過`4.17A`：

- 電源；
- 電線；
- 端子；
- 連接器；
- MOSFET或SSR；
- 保險絲和保險絲架；
- 電路板迹線（如果加熱器連接到電路板）。

如果電源額定為`24V 5A`，形式上接近負荷，但幾乎沒有餘量。對於真實設備，最好選擇更大的。

## 示例：多個負荷

假設`24V`設備有：

- 加熱器`100W`；
- 風扇`24V 0.2A`；
- LED燈帶`24V 1A`；
- 另一個風扇`24V 0.15A`。

計算加熱器：

```text
100W / 24V = 4.17A
```

將它們相加：

```text
4.17A + 0.2A + 1A + 0.15A = 5.52A
```

最小電源"緊湊型"將約為`24V 6A`，但這對於長期運作是個糟糕的選擇。使用`50%`餘量：

```text
5.52A * 1.5 = 8.28A
```

實際上，如果外殼、冷卻和安全允許，您應該查看`24V 9A`、`24V 10A`或更大電源。

## 餘量是必須的

電源、佈線、端子和電源模組不能根據計算電流精確選擇。

對於本指南，粗略第一次評估的簡單規則：

**計劃至少`50%`的餘量**，除非特定元件的檔案要求更多。這不是普遍保證，而是開始估計。最終選擇根據技術規格、外殼內溫度、冷卻、降額和端子/電線的實際加熱進行。

需要餘量的原因：

- 電源升溫；
- 外殼內的溫度可能高於室溫；
- 風扇和馬達有浪涌電流；
- 接觸點老化並鬆動；
- 端子有電流和溫度限制；
- SSR和MOSFET產生熱量；
- 電源可能有降額 - 在高溫或通風不良時最大功率降低。

工業電源通常在技術規格中有一條降額曲線——隨溫度升高最大功率降低的曲線。降額意味著在高溫或通風不良時，製造商降低最大允許功率。因此，電源上的`240W`標籤並不總是意味著在密閉熱外殼中能安全供應`240W`。

## 弱點可能不是電源

即使電源強大，電路可能在其他地方較弱。

您需要檢查整個電路：

- 電源輸出；
- 電線；
- 端子塊；
- 連接器；
- 保險絲；
- MOSFET模組；
- 繼電器或SSR；
- 電路板迹線；
- 負荷本身。

例如，電源可以承受`10A`，但小連接器或劣質螺絲端子在較低電流下可能已經升溫。這對加熱器和LED燈帶特別重要。

## 什麼是電源開關

電源開關是一種受控開關。

控制器不直接為重負荷供電。它給出弱控制信號，電源開關打開或關閉負荷電流。

例子：

- 用於`12V`/`24V` DC負荷的MOSFET模組；
- 繼電器；
- SSR；
- 現成的負荷驅動器；
- 電路板的標準輸出（如果為所需負荷額定）。

對於加熱器、風扇、LED燈帶和馬達，規則幾乎總是適用：

**控制器的GPIO不向負荷供電。GPIO僅控制。**

## 關於歐姆定律的一點

歐姆定律將電壓、電流和電阻相關聯：

```text
U = I * R
```

對於本文，簡單的想法很重要：如果您向負荷施加電壓，電流將通過它流動。流動多少電流取決於負荷本身。

但並非所有負荷都表現相同：

- 加熱器接近電阻負荷；
- 風扇和馬達有浪涌電流；
- 伺服驅動器在阻塞時電流急劇增加；
- LED燈帶按長度和亮度消耗電流；
- 電子模組打開時可能有瞬態電流。

因此，對於真實設備最好從技術規格獲取數據或用萬用表/實驗室電源測量電流（如果安全）。

## 連接前檢查的內容

在連接負荷之前，回答：

1. 負荷的額定電壓是多少？
2. 是DC負荷還是AC負荷？
3. 指定什麼電力或電流？
4. 您從公式`I = P / U`得到多少電流？
5. 同一電源上還有哪些其他負荷？
6. 至少有`50%`的餘量嗎？
7. 電線、端子、連接器和電路板能承受嗎？
8. 什麼控制負荷：MOSFET、繼電器、SSR或標準輸出？
9. 需要保險絲嗎？
10. 如果發生短路、馬達卡住或風扇故障會怎樣？

如果這是加熱器或商用電源`110-230V AC`，安全要求更高。商用段不能通過猜測組裝：您需要合適的外殼、保險絲、絕緣、保護接地`PE`、電線應力釋放和合格人員的驗證。

## 主要點

- 電源電壓必須與負荷電壓匹配。
- 電力顯示負荷的大小。
- 電流顯示對電線、端子、連接器和電源元件的負荷。
- 基本公式：`I = P / U`。
- 在`24V`系統中`24W`約`1A`，`120W`約`5A`，`240W`約`10A`。
- 一個電源上所有負荷的電流相加。
- 粗略第一次估計需要至少`50%`餘量；精確選擇根據技術規格、溫度、冷卻和降額進行。
- 弱點可能不是電源，而是端子、連接器、電線、MOSFET或電路板迹線。
- 控制器的GPIO不向重負荷供電，只控制電源開關。
