# 3D 列印

本節並非 3D 列印教程。

它的目的不同：幫助您理解哪些列印件可以安全地用於自製設備，哪些在加熱器、電子設備、配線和運動部件附近會成為風險。

在類似 iDryer 的項目中，3D 列印通常用於：

- 外殼；
- 蓋板；
- 風道；
- 風扇支架；
- 感應器支架；
- 導軌；
- 把手和夾子；
- 裝飾或維護面板。

列印零件很容易。讓它在溫暖的外殼中安全運行數個月則更難。

## 關鍵問題

在為設備列印零件之前，您必須回答的不僅是「STL 能否放入切片器」，還有幾個問題：

- 零件將位於何處；
- 那裡的溫度是多少；
- 附近有加熱器嗎；
- 附近有 110-230V AC 嗎；
- 零件將承受負載嗎；
- 它會接觸電線嗎；
- 它會輸送熱風嗎；
- 它能被更換或維護嗎；
- 如果它變形會發生什麼。

如果零件變形可能導致感應器移位、氣流阻塞、電線更靠近熱區或加熱器安裝鬆動，那它就不再只是「外觀缺陷」了。

## STL 不是組裝說明

STL 描述零件的形狀，但不告訴您：

- 用什麼材料列印；
- 用什麼方向列印；
- 要用多少牆厚；
- 要使用什麼填充率；
- 在哪裡需要支撐；
- 要使用什麼螺釘；
- 零件能承受什麼溫度；
- 它會在哪個方向較弱。

同一個模型根據材料、方向和工作條件，可能是一個普通蓋板或一個不佳的結構支架。

因此，一個工作零件需要的不僅是 STL，還需要上下文：材料、列印設置、安裝位置、負載和溫度狀態。

## 材料比外觀更重要

對於原型，PLA 通常可行。它易於列印並能生成外觀不錯的零件。

但對於靠近熱源的零件，PLA 是不佳的選擇。問題不在於它會立即熔化，而在於它在密閉外殼或加熱器附近的溫度下會逐漸失去剛度和形狀。

對於在烘乾機、室內或加熱器周圍的工作零件，您通常會考慮：

- ABS；
- ASA；
- 如果您有經驗和合適的印表機，更耐高溫的工程材料。

材料根據條件進行選擇：

- 工作溫度；
- 剛度；
- 抗衝擊性；
- 收縮和變形；
- 列印時的氣味和排放；
- 加熱時的行為；
- 製造商文檔。

## 外殼內的溫度

密閉外殼內的溫度不同於室溫。

即使加熱器不接觸塑膠，零件也可能：

- 在熱風流中；
- 靠近加熱器；
- 靠近散熱片；
- 靠近電源供應器；
- 在通風不良的區域；
- 在緩慢加熱的牆壁上。

因此，您無法僅用「零件不接觸加熱器」來評估安全性。您需要理解在延長運行期間該位置的溫度。

## 強度取決於層方向

FDM 零件在各個方向上的強度並不相等。

層方向影響零件的斷裂方式：

- 沿著塑膠線通常更強；
- 在層之間通常更弱；
- 薄柱子和夾子可能在層之間斷裂；
- 如果幾何不適配，螺釘可能導致零件分層。

對於結構支架，思考負載將往哪裡傳遞很重要。

如果風扇支架只是掛在牆上，那是一回事。如果支架支撐加熱器或線圈軸，列印方向和牆厚就變得重要。

## 外殼必須易於維護

一個好的外殼不只是一個漂亮的盒子。

它必須允許：

- 存取端子；
- 更換風扇；
- 檢查溫度感應器；
- 緊固件的緊固；
- 控制器的移除；
- 電線的更換；
- 查看是否有過熱或變色。

如果您需要拆卸設備的一半才能存取保險絲或端子，它將得到較少的維護。這是不佳的工程實踐。

## 列印零件不得危害安全

列印外殼可能很有用，但它不能把一個小錯誤變成危險的情況。

不好的情況：

- 加熱器支架軟化；
- 風道翹曲，通過加熱器的氣流減少；
- 溫度計支架移位；
- 電線與銳邊摩擦；
- 端子最終緊靠塑膠；
- 蓋板阻擋電源供應器的通風；

對於熱和受載區域，最好這樣想：如果列印零件變形，設備應該要么保持安全，要么進入錯誤狀態，而不是繼續盲目加熱。

## 本節不做的事

這裡不會有完整的 3D 列印課程。

我們不會深入討論：

- 世界上所有的塑膠；
- 回抽設置；
- 裝飾後處理；
- 藝術模型；
- 完美的印表機校正；
- 特定長絲品牌選擇。

重點很簡單：真實設備的零件必須足夠堅固、耐熱、易於維護和安全。

## 關鍵要點

- STL 僅是幾何形狀，不是安全的組裝說明。
- 根據工作溫度和負載選擇材料，而不是外觀。
- PLA 適合原型但在靠近熱源時有風險。
- 列印方向影響強度。
- 外殼應該分隔熱區、電子設備、電源配線和使用者區域。
- 列印零件不應是保護設備安全的唯一東西。
