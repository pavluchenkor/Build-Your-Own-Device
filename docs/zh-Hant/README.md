# 自製耗材乾燥機

本节帮助你設計并建構自己的耗材乾燥機或 3D 打印机主动加热箱体。內容包括電子基础、控制器选择、加熱器、風扇、感測器、外殼設計，以及第一次組裝前值得排查的常见錯誤。

不需要預先具备電子經驗。每篇文章只关注一个主题，并連結到相关材料。

## 內容

- `00-start-here/01-introduction.md` - 本节適合谁、如何阅读，以及为什么從簡單內容逐步进入複雜內容。
- `01-electronics-basics/` - 電壓、電流、功率、MOSFET、TRIAC 和 SSR。
- `02-controllers/` - ESP32、Arduino、RP2040、STM32、Klipper MCU 和通訊介面。
- `03-common-components/` - 加熱器、風扇、熱敏電阻、LED 燈帶、伺服馬達、称重感測器、顯示器和 RFID/NFC。
- `04-thermal-physics-and-materials/` - 熱、導熱、氣體、材料、可燃性和安全性。
- `05-tools/` - 萬用表、USB-TTL、焊接、壓接、ST-Link 和示波器。
- `06-practical-guides/` - 風扇、熱敏電阻、伺服馬達、称重感測器和 RFID 讀卡器的实际连接。
- `07-3d-printing/` - 列印件、STL、PETG/ABS/ASA、耐熱材料和外殼設計。
- `08-common-mistakes/` - 电源、接線、控制器、加熱器、SSR 的常见錯誤和诊断清單。
