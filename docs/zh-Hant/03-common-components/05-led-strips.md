# LED 燈條

LED 燈條是具有 LED 和電源迹跡的柔性主板。在印表機、烘乾機或小型 DIY 設備中，它通常用於室室照明、狀態指示、工作區照明或裝飾性外殼照明。

初學者的主要誤誤是將 LED 燈條視為小 LED。即使是短燈條也可以吸取比風扇更多的電流，長燈條成為完整的電源負載。

## 應用場景

在 3D 印表機周圍的 DIY 設備中，LED 燈條有用於：

- 印表機室室照明；
- 耗材烘乾機照明；
- 狀態指示：加熱、烘乾、錯誤、等待；
- 外殼內的工作區照明；
- 無主光的柔和夜間照明；
- 列印完成或出現錯誤時的視覺信號。

對於服務照明，簡單的白色燈條通常更好。對於模式指示，RGB 或可定址燈條很方便，但電源和控制更複雜。

## 電壓：5V、12V 或 24V

LED 燈條有不同的電壓：

- `5V` - 通常是可定址燈條，例如 WS2812/NeoPixel；
- `12V` - 常見的白色和 RGB 燈條；
- `24V` - 方便用於較長的部分和 24V 系統。

燈條電壓必須與電源相符。你無法將 `12V` 燈條連接到 `24V`。`24V` 燈條在 `12V` 上可能會變暗或無法工作。`5V` 燈條在 `12V` 或 `24V` 上幾乎肯定會被損壞。

如果你的印表機已經是 `24V`，這並不意味著任何燈條都可以連接到它。你需要購買恰好 `24V` 的燈條或放置適當電壓的 DC-DC 轉換器。

## 常規和可定址燈條

LED 燈條有兩種主要類型。

常規燈條一次性亮起。這可能是：

- 單色白色；
- 暖白/冷白；
- 沿整個長度改變顏色的 RGB 燈條；
- 具有單獨白色通道的 RGBW 燈條。

這樣的燈條在每個 LED 上沒有微晶片。亮度由電源開關或透過 MOSFET、LED 控制器或合適的主板輸出的 PWM 控制。

可定址燈條具有單個 LED 或 LED 組的控制微晶片。它讓你以不同顏色點亮不同的部分。典型的例子：WS2812B、SK6812、NeoPixel 兼容燈條。

可定址燈條需要：

- 正確電壓下的電源；
- 與控制器的共同 `GND`；
- 資料線 `DIN`；
- 沿燈條上箭頭的正確資料方向；
- 通常 - 5V 資料信號等級；
- 小心電源，沒有大下降。

對於簡單的室室照明，可定址燈條通常是大材小用。對於漂亮的指示和效果，它很方便，但需要更多對電源的關注。

## 電流和功率

選擇 LED 燈條不僅僅是按顏色和長度。你需要知道它的功率。

產品頁面通常列出：

- 電壓：例如 `12V` 或 `24V`；
- 每米功率：例如 `4.8 W/m`、`9.6 W/m`、`14.4 W/m`；
- 每米 LED 數量；
- LED 類型：例如 `3528`、`5050`、`2835`；
- 燈條寬度；
- 保護程度：裸露、矽膠套、IP65/IP67；
- 每個部分的最大長度。

電流計算很簡單：

```text
電流 = 功率 / 電壓
```

例子：你有 `2 m` 的 `24V` 燈條，功率為 `9.6 W/m`。

```text
總功率 = 2 m × 9.6 W/m = 19.2 W
電流 = 19.2 W / 24 V = 0.8 A
```

對於這樣的燈條，電源、MOSFET、線路和連接器必須舒適地處理超過 `0.8 A`。實際上，最好至少增加 `30-50%` 的裕度，特別是如果燈條長時間運行。

對於 RGB 燈條，你必須考慮所有通道的最大電流。RGB 上的白色通常意味著紅色、綠色和藍色通道同時開啟。

對於可定址 5V 燈條，粗略估計最亮白色時每個 RGB 像素最多 `60 mA`。在真實的效果中，電流可能較少，但你無法為「通常不是最高亮度」的電源和線路進行尺寸調整。

## 為什麼你無法從 GPIO 為燈條供電

控制器的 GPIO 是信號輸出，不是電源。

你無法直接將 LED 燈條連接到微控制器腳位。GPIO 的額定電流不適用於燈條電流。這可能會損壞主板、導致重新啟動、不穩定操作或迹跡過熱。

正確的邏輯：

- 燈條電流來自電源；
- 控制器只管理開/關、亮度或資料；
- MOSFET、LED 驅動器、LED 控制器或主板電源輸出處理電源開啟/關閉；
- 如果有控制信號，控制器和電源接地被連接。

## 連接簡單的單色燈條

對於白色 `12V` 或 `24V` 燈條，通常使用低端 MOSFET：燈條的加號連接到電源加號，燈條的減號由 MOSFET 模組開啟/關閉。

典型電路：

1. 電源 `+V` 進到 LED 燈條 `+`。
2. LED 燈條 `-` 進到 MOSFET 模組電源輸出。
3. 電源 `GND` 進到 MOSFET 模組。
4. 控制器 `GND` 連接到電源 `GND`。
5. 控制器控制腳位進到 MOSFET 模組輸入。

如果印表機主板已經有用於風扇或 LED 的受管輸出，只有在為所需的電壓和電流額定時才可使用。你無法在不檢查輸出限制的情況下將長燈條連接到任何隨意的連接器。

## RGB 燈條

典型的 RGB 燈條通常具有共同的加號和三個受管的減號：

- `+V`；
- `R`；
- `G`；
- `B`。

每個顏色通道需要單獨的 MOSFET 通道或現成的 RGB 控制器。整個 RGB 燈條的一個 MOSFET 只能開啟和關閉它，無法改變顏色。

為 RGB 燈條選擇 MOSFET 模組時，查看每個通道的電流和總電流。連接器、終端和線路也必須處理負載。

## 可定址燈條

可定址燈條通常具有：

- `+5V` 或如果不是 5V 型號的其他電源；
- `GND`；
- `DIN` - 資料輸入；
- 有時 `DOUT` - 資料輸出到下一個部分。

重要的規則：

- 向燈條上的箭頭方向連接資料；
- 控制器和燈條必須有共同的接地；
- 對於 3.3V 控制器上的 5V 可定址燈條，你通常需要電壓轉換器；
- 在長燈條之前，跨電源的電解電容器很有用；
- 在靠近燈條輸入的資料線中通常放置約 `300-500 歐` 的電阻；
- 對於長燈條，最好不僅在開始時供電，還在其他位置供電。

如果可定址燈條從單獨的電源供電，你無法僅應用 `DIN` 而無共同的 `GND`。資料信號隨後沒有適當的參考等級，燈條將隨意閃爍或無法工作。

## 電壓降和多點電源

長 LED 燈條在開始可能很亮，在末尾明顯變暗。這不是「控制器差」，而是線路和燈條銅迹上的電壓降。

電壓越低且電流越高，問題越糟。所以 `5V` 和 `12V` 燈條比相同功率的 `24V` 燈條更經常需要來自多個位置的電源。

電壓降的跡象：

- 燈條末端較暗；
- RGB 上的白色轉移為黃色或紅色；
- 可定址燈條在明亮效果期間閃爍；
- 當變亮時控制器重新啟動；
- 線路、連接器或燈條開始變熱。

解決方案：

- 在適當的電壓下使用燈條；
- 使用具有足夠規格的線路；
- 對長部分的開始和末尾施加電源；
- 將長燈條分成多個部分；
- 在電源線上使用保險絲；
- 不要將所有電流通過弱連接器或薄迹路。

## 熱和安裝

LED 燈條本身產生熱。這對於矽膠套中的明亮燈條和安裝在密閉外殼內的燈條特別明顯。

不良的安裝位置：

- 靠近加熱器；
- 在溫暖的室室內的軟 PLA 上；
- 在不散熱的表面上；
- 燈條觸及移動零件的地方；
- 在經常在沒有連接器的情況下移除的蓋上。

為了延長壽命，最好將燈條安裝在鋁製槽或其他散熱表面上。如果燈條在印表機室室內，考慮室室溫度和粘合劑層溫度。

## 購買前要檢查的事項

在購買 LED 燈條之前，檢查：

- 燈條電壓；
- 每米功率；
- 總長度；
- 顏色：白色、RGB、RGBW、可定址；
- 控制類型；
- 燈條寬度和安裝位置；
- 安裝位置溫度；
- 你是否需要鋁製槽；
- 你是否需要 MOSFET 模組或 LED 控制器；
- 電源是否可以處理額外的負載；
- 是否有適當的維護連接器。

對於印表機室室，`24V` 白色燈條通常在整個系統已經 `24V` 時更實用。對於小型 ESP32 指示器，短 `5V` 可定址燈條可能很方便。對於長裝飾性 RGB 照明，最好提前計算電流並考慮多點電源。

## 常見錯誤

- 將燈條連接到錯誤的電壓；
- 從 GPIO 為燈條供電；
- 未計算整個長度的電流；
- 選擇沒有裕度的 MOSFET 模組；
- 用薄線連接長燈條；
- 忘記控制器和燈條之間的共同接地；
- 將可定址燈條資料連接到 `DOUT` 而不是 `DIN`；
- 在需要時未從 3.3V 控制器安裝 5V 可定址燈條的電壓轉換器；
- 僅對長燈條的一端供電；
- 在無溫度檢查的熱區安裝燈條；
- 在可移除的蓋上留下燈條，沒有連接器。

## 要點

LED 燈條不是信號 LED，而是負載。首先檢查電壓和功率，然後計算電流、選擇線路、MOSFET 或控制器，最後才連接到主板。

對於簡單的照明，在系統電壓下選擇常規白色燈條。對於效果和指示，你可以使用可定址燈條，但電源、共同接地、信號等級和電壓降保護特別重要。
