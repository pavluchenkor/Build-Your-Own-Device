# 加熱器和 SSR 錯誤

加熱器是簡單 DIY 設備中最危險的負載。

風扇可能無法啟動。感應器可能提供錯誤讀數。但有錯誤的加熱器可能過熱外殼、熔化塑膠、損傷配線或造成火災風險。

如果設備有 110-230V AC 而您不理解電氣安全，正確的行動是停止並向專家尋求幫助。

## 症狀

危險跡象：

- SSR 明顯加熱；
- 加熱器無法關閉；
- 溫度升高儘管命令是關閉；
- 溫度升高太快或不合理；
- 溫度感應器顯示錯誤值；
- 端子變暗；
- 電線或連接器加熱；
- 斷路器或保險絲跳閘；
- 外殼聞起來像塑膠或燃燒；
- 設備危險到觸摸；
- 控制器錯誤後加熱繼續。

如果加熱器表現不如預期，關閉電源。

## AC SSR 和 DC SSR 混淆

SSR 有不同負載類型。

AC SSR 是用於交流。DC SSR 是用於直流。

錯誤：

- AC SSR 放在 DC 加熱器上；
- DC SSR 放在 230V AC 上；
- 買「SSR 40A」不理解外殼上寫的是什麼。

錯誤的 SSR 類型可能無法關閉負載或危險工作。

連接前驗證：

- 輸出類型：AC 或 DC；
- 允許的負載電壓；
- 允許的電流；
- 控制輸入電壓；
- 製造商連接圖；
- 是否需要散熱片。

## SSR 無散熱片

SSR 在運行時加熱。

即使外殼說大電流，也不意味著繼電器在密閉外殼中無散熱片會處理。

檢查：

- 負載電流；
- SSR 上的電壓降；
- 散逸功率；
- 散熱片要求；
- SSR 外殼溫度運行後；
- 是否有氣流。

如果 SSR 太熱難以用手按住，這是停止和理解的原因。

## 用於 110-230V AC 的 MOSFET

Arduino/ESP32 的常規 MOSFET 模塊通常用於 DC 負載：12V 或 24V。

它們無法用作 AC 主線 110-230V 的簡單開關。

對於主線負載，您需要不同的組件、不同的隔離、不同的端子、接地、保險絲和對電氣安全的理解。

如果不確定所選模塊是為主線負載設計的，不要將其連接到主線。

## 沒有保險絲

保險絲不能使設備完全安全，但它限制一些故障的後果。

不好的想法：

- 「我稍後會添加它」；
- 「電源供應器會保護自己」；
- 「我的加熱器很小」；
- 「如果保險絲燒斷我會放更大的」。

保險絲根據電路、配線和負載選擇。它不能僅因為跳閘就增加。

如果保險絲跳閘，找到原因。

## 沒有獨立熱保護

韌體和溫度感應器不是唯一的保護。

對於加熱器，獨立硬體保護很有用：

- 溫度計；
- 熱保險絲；
- 雙金屬開關；
- 單獨的緊急加熱器電源切斷。

這樣的保護必須獨立於控制器和韌體工作。

如果控制器掛起、引腳在打開狀態掛起、SSR 失敗或感應器斷開連接，硬體保護可能是最後一道防線。

## 溫度感應器安裝不佳

加熱器由來自感應器的反饋控制。

如果感應器：

- 斷開連接；
- 按得不牢；
- 在錯誤地方；
- 沒有熱接觸；
- 顯示空氣溫度而非加熱器；
- 在韌體中選擇了錯誤類型；

控制器可能因讀取錯誤溫度而繼續加熱。

不佳的熱接觸是加熱系統中最危險的錯誤之一。

## 錯誤的加熱器功率

加熱器功率必須在連接前計算。

例子：

```text
24V 120W -> 5A
24V 240W -> 10A
230V 300W -> 大約 1.3A
```

對於低電壓強力加熱器，電流很快變得大。這需要合適的電線、端子、MOSFET/SSR 和電源供應器。

對於主線加熱器電流更少但電擊危害更高。

## 弱端子和電線

「有點保持」的端子在電流下可能加熱。

原因：

- 接觸不佳；
- 絕緣被夾緊；
- 電線太薄；
- 端子不適合電流；
- 絞線無套管散開；
- 螺釘被熱和振動鬆動。

變暗的端子、氣味、加熱或塑膠在周圍軟化是關閉設備的原因。

## 不能做什麼

您無法：

- 在電源下持有開放主線部分；
- 在電源下改變電線；
- 為 230V AC 使用 Arduino MOSFET 模塊；
- 如果需要無散熱片使用 SSR；
- 禁用熱保護；
- 短路緊急溫度計；
- 增加保險絲「所以它不燒斷」；
- 在首次測試時無人看管加熱器；
- 在加熱器附近使用 PLA 安裝。

## 要檢查的內容

首次加熱前：

1. 加熱器電壓。
2. 功率和電流。
3. 電源開關類型：MOSFET、AC SSR、DC SSR、繼電器。
4. 電流邊距。
5. SSR 或 MOSFET 散熱片（如果需要）。
6. 保險絲。
7. 接地（如果需要）。
8. 端子和電線。
9. 溫度感應器安裝。
10. 韌體中正確的 `sensor_type`。
11. `min_temp` 和 `max_temp`。
12. 獨立的熱保護。
13. 控制器關閉時的行為。
14. 簡短測試後的端子和 SSR 溫度。

## 要點

- 加熱器無法像普通小負載一樣測試。
- AC SSR 和 DC SSR 是不同的設備。
- SSR 通常需要散熱片。
- 用於 DC 負載的 MOSFET 模塊不適用於 110-230V AC。
- 溫度感應器必須牢固安裝在正確位置。
- 硬體熱保護必須獨立於韌體。
- 如果有氣味、端子加熱或不尋常的加熱器行為，關閉電源。
