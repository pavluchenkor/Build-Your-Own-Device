# 常見錯誤

本節不是來批評您。

它是來幫助您快速識別 DIY 設備中的常見錯誤：下垂的電源供應器、鬆散的電線、顯示垃圾的感應器、重新啟動的控制器、表現奇怪的加熱器。

本節格式很簡單：

- 症狀；
- 可能的原因；
- 要檢查的內容；
- 不能做什麼；
- 如何安全修復。

## 診斷的主要規則

如果設備表現奇怪，您不應立即改變韌體、重新焊接一切或增加電源。

首先，驗證基本面：

1. 電源供應器；
2. 極性；
3. 共同 `GND`；
4. 端子和連接器；
5. 感應器；
6. 電源開關；
7. 韌體和配置。

簡單設備中的大多數問題不是「複雜電子設備」，而是電源供應器、配線或不正確的連接。

## 何時停止

如果出現以下情況，立即關閉電源：

- 燃燒氣味出現；
- 電線加熱；
- 端子加熱；
- 連接器變暗；
- 外殼在意外位置變熱；
- 加熱器無法關閉；
- 斷路器或保險絲跳閘；
- 溫度感應器顯示垃圾；
- 設備僅在您移動電線時工作。

不要「再打開一次看看」。如果有東西在加熱、聞起來或發出火花，在沒有電源的情況下先找到原因。

## 錯誤的主要分組

在本節中，錯誤被分組為：

- `02-power-mistakes.md` - 弱電源供應器、錯誤電壓、下垂、薄電線、沒有邊距。
- `03-wiring-mistakes.md` - 反向極性、不佳的端子、沒有共同接地、不佳的連接器。
- `04-controller-mistakes.md` - 不適合的板、3.3V/5V 邏輯、GPIO 而非電源輸出、不正確的韌體。
- `05-heater-ssr-mistakes.md` - 加熱器、SSR、MOSFET、110-230V AC、溫度感應器、散熱片和保護。
- `06-diagnostic-checklist.md` - 設備無法工作或表現奇怪時的一般驗證順序。

## 為什麼電源供應器首先被檢查

電源供應器影響幾乎一切。

如果電源供應器弱或電線薄，症狀可能看起來像韌體問題：

- 控制器重新啟動；
- Wi-Fi 掉線；
- 屏幕閃爍；
- 伺服抖動；
- 風扇無法啟動；
- 感應器顯示隨機值；
- 加熱器加熱效果差。

在用萬用表在負載下檢查電源供應器之前，很難自信地診斷一切。

## 為什麼配線比看起來更重要

不佳的連接可以「幾乎正常」工作。

這正是危險的地方：

- 今天它工作；
- 當振動時它斷開連接；
- 當加熱時，接觸變得更糟；
- 端子逐漸變暗；
- 電線開始加熱；
- 感應器出現和消失。

如果設備在移動電線時改變行為，這不是軟體錯誤。這是連接問題。

## 為什麼不應禁用保護

溫度失控、`MINTEMP`、`MAXTEMP`、`加熱器不加熱` 和類似錯誤存在不是為了惱怒使用者。

這些是控制器不再信任溫度讀數或看到危險加熱行為的跡象。

不好的想法：

- 禁用熱保護；
- 擴展溫度限制而不理解原因；
- 用更大的保險絲替換保險絲；
- 直接短路溫度計；
- 短路保護「用於測試」。

正確的想法：找到保護觸發的原因。

## 如何閱讀本節

如果設備根本無法工作，從診斷檢查清單開始。

如果症狀很清楚，去相關文章：

- 重新啟動、閃爍、弱熱 - 電源供應器；
- 在移動電線時工作 - 配線；
- 板無法檢測或引腳無反應 - 控制器；
- 加熱器無法關閉或 SSR 加熱 - 加熱器和 SSR；
- 一切不清楚 - 一般檢查清單。

## 要點

- 大多數錯誤開始於電源、配線和不正確的連接。
- 如果有東西在加熱、聞起來或變暗，關閉電源。
- 診斷從簡單進行到複雜。
- 韌體保護和硬體保護不應為了便利而禁用。
- AC 主線 110-230V 無法在沒有理解電氣安全的情況下「在工作台上」診斷。
