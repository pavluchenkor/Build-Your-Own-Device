# 萬用表

萬用表是主要的第一線診斷工具。

你可以用它檢查：

- 電源是否存在；
- 電壓是否正確；
- 正極和負極在哪裡；
- 電線是否斷裂；
- 保險絲是否完好；
- 熱敏電阻是否似乎功能正常；
- 在負載下是否有電壓下垂。

但是如果你混淆了模式，很容易用萬用表犯錯。最危險的錯誤涉及測量電流和主電壓。

## 探針和端口

萬用表通常有：

- `COM` - 公共端口，幾乎總是插入黑色探針；
- `V/Ohm/mA`或類似端口 - 用於電壓、電阻、連續性和小電流；
- `10A`或`A` - 用於大電流的單獨端口。

測量前，始終檢查：

- 紅色探針插入哪個端口；
- 選擇了什麼模式；
- 你究竟要測量什麼。

一個非常常見的錯誤：測量電流後，你忘記將探針從`A`移回`V/Ohm`，然後嘗試測量電壓。這可能導致短路。

## 測量直流電壓

直流是直接（恆定）電壓。在我們的設備中，這通常是：

- `3.3V`；
- `5V`；
- `12V`；
- `24V`。

程序：

1. 黑色探針插入`COM`。
2. 紅色探針插入`V`端口。
3. 選擇直流電壓模式：通常`V`帶有直線。
4. 黑色探針放在負極或`GND`。
5. 紅色探針放在正極。
6. 讀取顯示屏。

如果顯示屏上的數字前出現負號，探針交換了。這很有用：你可以用這種方式確定極性。

## 在何處測量電壓

不要將自己限制在電源輸出。

檢查：

- 在電源終端；
- 在板輸入；
- 在負載終端；
- 在直流-直流模組；
- 在風扇上；
- 在伺服上；
- 在LED條帶上。

如果電源顯示24V，但負載顯示明顯較少，請在電線、終端或連接器上查找下垂。

對於電源診斷，重要的是在負載下測量，而不僅僅是空轉。

## 測量交流電壓

交流是交流電壓，例如來自主電源的110-230V。

主電壓很危險。

如果你不理解自己在做什麼，不要用萬用表測量開放的主電源部分。最好使用現成的安全模組、密閉終端和專家幫助。

如果你確實測量，你需要：

- 一個具有安全等級**CAT II**或**CAT III**的萬用表 — 這寫在設備本體上，靠近電壓，例如`CAT II 600V`。CAT I不適合家用主電源。CAT III和CAT IV為更複雜的安裝提供額外的邊距；
- 正常工作的探針，等級不低於萬用表；
- 乾燥的手；
- 密閉和穩定的組裝；
- 理解相位和中性線在哪裡；
- 沒有意外的開放接觸點。

對於大多數涉及低電壓電子產品的任務，直流測量是足夠的。

## 連續性檢查

連續性顯示兩點是否電連接。

檢查很有用：

- 如果電線完好；
- 如果`GND`已連接；
- 如果電纜未斷裂；
- 如果按鈕有效；
- 如果保險絲完好；
- 相鄰接觸點是否短路。

程序：

1. 關閉電源。
2. 將萬用表設置為連續性模式：通常是聲音圖標或二極體符號。
3. 將探針彼此觸摸 - 應該有嗶聲。
4. 觸摸要檢查的兩個點。
5. 如果發出嗶聲，這些點之間有導電連接。

連續性檢查在斷電電路上進行。

## 電阻

電阻以歐姆為單位測量。

對於我們的任務，這是必要的：

- 檢查熱敏電阻；
- 檢查斷線；
- 檢查保險絲；
- 確定是否存在短路；
- 檢查電阻器。

重要：電阻僅在斷電電路上測量。

如果你在通電的電路板上測量電阻，你可能會得到不正確的讀數或損壞萬用表。

## 測試熱敏電阻

對於典型的NTC`100K`在室溫下，預計數十或約`100 kOhm`。

如果萬用表顯示：

- `OL`或無窮大 - 可能是開路；
- 幾乎`0 Ohm` - 可能是短路；
- 當你移動電線時值波動很大 - 接觸不良；
- 當被手指加熱時電阻減小 - 看起來像活躍的NTC。

確切的值取決於熱敏電阻類型和溫度。

## 測量電流

測量電流比測量電壓更危險。

電壓並聯測量：探針接觸兩個點。

電流是串聯測量：你必須破壞電路並將萬用表連接進去，以便電流流過設備。

錯誤 - 將萬用表置於電流模式，並將探針觸摸到電源的正極和負極。那幾乎是通過萬用表的短路。

對於初學者，最好是：

- 首先從功率計算電流；
- 使用現成的瓦特表/USB功率表/直流功率表；
- 僅當你理解如何將萬用表串聯連接時才測量電流；
- 從正確的範圍和正確的端口開始。

## 檢查保險絲

檢查斷電電路上的保險絲。

方法：

- 連續性；
- 電阻測量。

好的保險絲通常顯示連續性並具有非常低的電阻。

燒斷的保險絲通常不顯示連續性。

如果保險絲吹斷，你不能只安裝更高額定值的保險絲。首先找到原因。

## 如何不燒毀萬用表

最低規則：

- 測量前檢查模式；
- 測量前檢查紅色探針端口；
- 不要在通電電路上測量電阻；
- 不要像測量電壓那樣測量電流；
- 不要在不理解安全的情況下進入110-230V交流電；
- 如果萬用表不是自動量程，請從更高的範圍開始；
- 使用工作探針；
- 不要用手指觸摸金屬尖端。

## 實際場景

檢查24V電源：

1. 直流電壓模式。
2. 黑色探針放在負極。
3. 紅色探針放在正極。
4. 應該讀約24V。

檢查風扇：

1. 在風扇連接器上測量電壓。
2. 檢查極性。
3. 檢查啟動時的電壓。

檢查斷線：

1. 斷開電源。
2. 連續性模式。
3. 探針在電線的兩端。
4. 沒有嗶聲 - 可能是開路。

檢查`+`和`GND`之間的短路：

1. 斷開電源。
2. 檢查`+`和`GND`之間的連續性。
3. 如果在不應該的地方發出嗶聲，請尋找短路。

## 要點

- 對於直流電壓，使用帶有直線的`V`模式。
- 電阻和連續性僅在斷電電路上進行。
- 電流是串聯測量，而不是並聯。
- 測量電流後，將探針從`A`移回正常的`V/Ohm`端口。
- 主電壓很危險；在不理解安全的情況下不要測量開放的110-230V部分。
- 負載下的萬用表常常會發現空轉時看不見的問題。
