# 熱伝導率

熱伝導率は、材料がその中を通して熱をどのくらい簡単に転移させるかを示します。

自作ドライヤ、チャンバ、フィルタ、エアダクト、またはハウジングの場合、これは抽象物理学ではありません。熱伝導率は、熱が外側に逃げるか、ヒータの近くにホットスポットが現れるか、外壁がどのくらい加熱されるか、印刷部品が軟化するかを決定します。

## 簡単な考え

熱は常に、より高温のゾーンからより低温のゾーンへ逃げようとします。材料の熱伝導率が高いほど、熱がそれをより簡単に通過します。

熱転移の速度に影響する要因：

- 材料
- 壁の厚さ
- 接触面積
- 温度差
- 部品間の接触品質
- 空気、隙間、および断熱材の存在

薄いアルミニウムプレートはハウジング全体に素早く熱を広げることができます。逆に、ミネラルウールまたはフォーム断熱材の厚い層は、熱が逃げるのを防ぎます。

## 材料参考値

以下の値は、大きさの順序を理解するためだけです。実際のビルドについては、特定の材料のデータシートを確認してください。

| 材料 | 近似熱伝導率、`W/(m*K)` | 実践的に何を意味するか |
| --- | ---: | --- |
| 銅 | 約`400` | 優秀な熱導体、熱散散に適しており、必ずしも必要ではない場所に熱を素早く転移させる可能性がある |
| アルミニウム | 約`200-240` | 熱をよく分散させ、プレート、ラジエータ、または熱スプレッダとして有用 |
| 鋼 | 約`15-60` | アルミニウムより悪く熱を伝導するが、ねじと柱はまだ熱橋になる可能性がある |
| ガラス | 約`1` | 金属より熱伝導率が低い、ただし通常の意味での断熱ではない |
| 一般的なプラスチック | 約`0.1-0.5` | 熱をほとんど伝導しないが、軟化および可燃性になる可能性がある |
| ミネラルウール、ガラス繊維 | 約`0.04` | 効果的に熱損失を低減するが、ほこり、湿気、機械的損傷からの保護が必要 |
| 発泡ポリスチレン/ポリウレタンフォーム | 約`0.03` | 良い断熱材、ただし熱の近くで、動作温度と火災特性が重要 |
| 空気 | 約`0.026` | それ自体の熱伝導率は低いが、動いているときは対流で熱を転移させる |

主な結論：金属と断熱材は2倍ではなく、桁違いに異なります。したがって、わずかな金属部品でも熱像全体を大きく変える可能性があります。

## 熱橋

熱橋は、熱が構造の他の部分より簡単に逃げるパスです。

![エンクロージャを通る古典的な熱橋](../../../img/04-thermal-physics-and-materials/02-thermal-bridge-classic.png)

*出典：[Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Pont_thermique_classique.png)、AmisDeLaThermique、CC BY-SA 3.0*

典型的な熱橋：

- 断熱壁を通る金属ねじ
- 外部ハウジングに接続されたアルミニウムプレート
- ホットチャンバと外部パネルの間の金属柱
- ヒータの近くの端子ブロックまたはファスナ
- ホット部品に直接接触するエアダクト

熱橋は常に悪いわけではありません。時々、ヒータ、ラジエータ、またはホットノードから熱を散散させるために必要です。問題は、橋が偶発的な場合に始まります：チャンバは熱を失い、外表面は熱くなり、橋の近いプラスチックは予想より加熱されます。

## 金属：ヒートシンクまたは偶発的な加熱

金属は加熱デバイスで使用するのに便利です：

- ヒータとプラスチック間のスクリーン
- 熱分散プレート
- ヒータマウント用のベース
- パワーエレクトロニクス用のラジエータ
- 非可燃性の内部表面

しかし、金属はデバイスを自動的に安全にしません。金属プレートがホットゾーンと外部ハウジングに接触する場合、外側に熱を伝導できます。プラスチックがそれにねじ止めされている場合、そのプラスチックはファスナを通って加熱される可能性があります。ワイヤがそれを通過する場合、エッジの近くに、かじり損傷からの保護が必要です。

## 断熱：損失低減、より多くの責任

断熱は熱損失を低減しますが、温度制御を排除しません。

チャンバを断熱する場合：

- ヒータの温度を上げやすくなります
- ハウジングは外側でより冷たくなる可能性があります
- 冷却時間が増加します
- ヒータの近い局所温度が上昇する可能性があります
- ファン故障またはスイッチ固着がより危険になります

したがって、断熱は「改善」として追加することはできません。断熱後、チャンバ内の温度、ヒータ、ワイヤ、端子、外表面を再度測定する必要があります。

## 空気間隙も機能

静止している空気は熱をほとんど伝導しません。したがって、空気間隙、二重壁、およびフォーム材料は熱転移を低減できます。

しかし、空気が動き始めると、対流が始まります。次に、熱は、単なる熱伝導ではなく、空気流によって転移されます。したがって、ホット流が流れる間隙は、流れがない厚い壁より多くのハウジングを加熱できます。

実際には、これは次を意味します：

- ヒータの近くで偶発的な隙間を残さないでください
- ホット流をプラスチックに直接向けないでください
- ストリームが通る場合、空気間隙を保護として扱わないでください
- 冷たいデバイスではなく、実際の動作モードで温度を確認してください

## 材料データシートで探すもの

熱の近くの材料については、熱伝導率だけが重要ではありません。

確認してください：

- 最大連続動作温度
- 軟化温度または熱変形温度
- 可燃性および火災動作クラス
- ホット空気との接触許可性
- 接着剤層、フォイル、コーティング、またはラミネーションの動作
- 製造業者の使用推奨事項
- 材料が加熱または処理できる場合はSDS/安全データシートの入手可能性

材料に明確なドキュメントがない場合、ヒータの近くに配置しないでください。唯一の保護として使用しないでください。

## 実用的な検証順序

ハウジング、チャンバ、またはドライヤの場合、次のように進めると便利です：

1. ホットゾーンを特定してください：ヒータ、空気出口、端子、電源スイッチ
2. ホットゾーンをプラスチックから金属、セラミック、または別の適切な材料で分離してください
3. 金属が熱をどこに伝導するかを確認してください
4. 危険なホットノードをカバーしない場所にのみ断熱を追加してください
5. ウォームアップ後、数点での温度を測定してください
6. ヒータが気流に依存している場合、ファン故障モードを確認してください
7. 過熱が危険な場所に独立した過熱保護を追加してください

1つの温度センサはチャンバ全体の熱像を表示しません。ヒータの近く、ファスナ、ワイヤ、ハウジング、および印刷部品での測定が必要です。

## 主な結論

熱伝導率は、熱が実際にどこへ行くかを理解するのに役立ちます。金属は有用なヒートシンクまたは偶発的な熱橋になる可能性があります。断熱は効率を改善できますが、同時に故障の結果を増幅できます。

ハウジング、断熱材、ファスナ、またはエアダクトへの変更は、実際の動作モードで温度を測定して確認する必要があります。
