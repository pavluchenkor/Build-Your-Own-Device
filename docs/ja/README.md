# フィラメント乾燥機を自作する

このセクションは、3Dプリンタ用のフィラメント乾燥機やアクティブ加熱チャンバーを自分で設計・製作するためのものです。電子回路の基礎、コントローラの選び方、ヒーター、ファン、センサー、筐体設計、最初の製作前に潰しておきたい典型的なミスを扱います。

電子工作の経験は前提にしていません。各記事はひとつのテーマに絞り、関連する資料へリンクしています。

## 内容

- `00-start-here/01-introduction.md` - このセクションの対象読者、読み方、簡単な内容から複雑な内容へ進む理由。
- `01-electronics-basics/` - 電圧、電流、電力、MOSFET、TRIAC、SSR。
- `02-controllers/` - ESP32、Arduino、RP2040、STM32、Klipper MCU、通信インターフェース。
- `03-common-components/` - ヒーター、ファン、サーミスタ、LEDストリップ、サーボ、ロードセル、ディスプレイ、RFID/NFC。
- `04-thermal-physics-and-materials/` - 熱、熱伝導、気流、材料、可燃性、安全。
- `05-tools/` - マルチメータ、USB-TTL、はんだ付け、圧着、ST-Link、オシロスコープ。
- `06-practical-guides/` - ファン、サーミスタ、サーボ、ロードセル、RFIDリーダーの実用的な接続。
- `07-3d-printing/` - 3Dプリント部品、STL、PETG/ABS/ASA、耐熱材料、筐体設計。
- `08-common-mistakes/` - 電源、配線、コントローラ、ヒーター、SSRの典型的なミスと診断チェックリスト。
