# 組み立てと確認

このページでは、デバイスをケースに組み立て、最初の制御された加熱実行と安全性の確認を行います。チェックは順序に従い、初回起動時にデバイスを無人に放置しないでください。

## 装置の順序

1. ケース内にESP32と電力部をマウントし、弱電力と電力ゾーンが分離されている場合。
2. シャフト内にSHT31センサーを配置しますが、加熱器からの直接流れから離れてください。そうしないと、体積内の空気温度ではなく、流れの温度を表示します。
3. 加熱器と熱接触で温度計を固定します。
4. ワイヤがヒーターに接触せず、ファンに入らないことを確認してください。
5. バージョンB（`220V`）では、ネットワイヤがターミナルに固定されており、断熱材が完全であり、ケースが接地されていることを確認してください。

ケースと構成要件 - [ケース設計](../07-3d-printing/05-enclosure-design.md)。

!!! warning "加熱に近い印刷部分"
    PLAはヒーターの近くで簡単に見つかる温度で柔らかくなります。加熱材料の近くの部品は耐熱材料から印刷してください。[耐熱材](../07-3d-printing/04-heat-resistant-materials.md)と[PLAが危険な理由](../07-3d-printing/06-why-pla-is-risky.md)を参照してください。

## 電力前のチェック

最初の起動前にマルチメーターで鳴らしてください：

- 電力とグラウンド間の短い回路なし；
- センサーの電力は`3.3V`で、`5V`ではありません；
- コントローラーと電力ブロック電源の共通グラウンド；
- 温度計と分圧器が正しく組み立てられています；
- バージョンBでは、ケースアース、ヒューズ、確実なターミナル。

マルチメーター使用方法 - [マルチメーター](../05-tools/02-multimeter.md)。

## 初回起動

1. コントローラーとセンサーのみに電力を供給します（可能であれば、負荷をまだ接続しません）。
2. デバイスがポータルでオンラインで、温度と湿度を表示していることを確認してください。
3. 加熱器とファンに接続します。
4. ポータルから加熱保持モードを開始し、観察します。

!!! danger "初回加熱を無人に放置しないでください"
    初回起動時はデバイスを監視します。加熱器が目標に達してオフになり、温度計保護によってではなく、継続的には機能しないことを確認してください。

最初の数分で観察することは：

- 空気温度が上昇し、目標の周辺で安定化します；
- 加熱器の温度が設定されたキャップを超えないようにしてください；
- ヒートが目標に達した時点でオフになり、ヒステリシスで冷却した後にオンになります；
- ファンは機能し、ワイヤには接触しません；
- 負荷をオンする際、コントローラーは再起動されません。

## 校正

初回加熱後、ポータル内のセンサーが別のシャフル温度計を備えています：

- シャフル内の空気温度が目標と異なるか - SHT31配置を確認します（流れや壁の近くにあってはいけません）；
- 加熱器温度が信じられない場合 - 温度計タイプと分圧器抵抗定格を確認します；
- 必要に応じて、[メニュー](06-menu.md)の目標温度とヒステリシスを調整してください。

## 何か機能していない場合

| 症状 | どこを見る |
|---------|---------------|
| 負荷でコントローラーが再起動 | [電力エラー](../08-common-mistakes/02-power-mistakes.md) |
| センサーが表示する「ナンセンス」 | [配線エラー](../08-common-mistakes/03-wiring-mistakes.md)、[温度計チェック](../06-practical-guides/02-checking-thermistor.md) |
| デバイスがWi-Fiに接続しない | [コントローラーエラー](../08-common-mistakes/04-controller-mistakes.md) |
| ヒーター/SSRは非常に熱い | [加熱器とSSRエラー](../08-common-mistakes/05-heater-ssr-mistakes.md) |

診断の一般的なシーケンス - [診断チェックリスト](../08-common-mistakes/06-diagnostic-checklist.md)。

## 持続的な操作の前のチェックリスト

- [ ] デバイスは目標温度を保ちます。継続的には機能しません。
- [ ] 温度計による加熱器保護がアクティブになります。
- [ ] ワイヤがヒーターとファンに接触しません。
- [ ] ヒートに近い印刷部分は耐熱です。
- [ ] バージョンBでは、ケースはアースされ、ヒューズがインストールされ、断熱材が完全です。
- [ ] ポータルのデータはシャフル内の実際の温度に対応しています。

## 結論

あなたはESP32とidryer-coreでフィラメント保管加温シャフトを構築しました：デバイスはクライメート構造と加熱器温度を読む、設定温度を保つ、加熱器を過熱から保護し、ポータルから制御されます。これはエコシステムの独自モジュールを構築できる完全な基盤です。

さらなるコンポーネント - LED照明、スケール、RFID - コアもサポートしています。同じスキーム：センサーまたはペリフェリー → テレメトリーまたはコマンド → ポータル表示でそれらを追加できます。
