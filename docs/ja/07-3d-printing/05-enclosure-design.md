# フィラメント乾燥機の筐体とアクティブ加熱チャンバー

筐体は、装置がどれだけ均一に温度を保てるか、ヒーターと電子部品をどれだけ安全に配置できるか、乾燥機をどれだけ保守しやすいかを決めます。このページでは、フィラメント乾燥機、アクティブチャンバー、類似の加熱モジュール向けの筐体設計の考え方を説明します。

筐体は部品を囲う箱ではありません。

安全に保持すべきものがあります。

- ヒーター。
- ファン。
- センサー。
- 電源。
- コントローラ。
- 端子。
- 配線。
- コネクタ。
- ディスプレイまたはボタン。
- 機械部品。

加熱機器では、電子回路が良くても悪い筐体が問題を作ります。気流を塞ぐ、コントローラを過熱させる、配線を擦る、樹脂を高温部に近づける、などです。

## 部品配置から始める

筐体をモデリングする前に、実物の部品を並べます。

- コントローラ基板。
- 電源または DC-DC コンバータ。
- ファン。
- ヒーター。
- 温度センサー。
- 端子。
- ヒューズ。
- 配線。
- コネクタ。
- ボタン、ディスプレイ、RFID、その他モジュール。

筐体は「だいたいこの大きさ」ではなく、実際の部品寸法を基準に設計します。

確認すること:

- コネクタの位置。
- USB の取り出し方向。
- リセットボタンを押せる場所。
- カバーをどう外すか。
- ファンをどう交換するか。
- 電源線がどこを通るか。
- 基板をどう固定するか。

## ゾーンを分ける

加熱機器では、ゾーンで考えると安全です。

- 高温ゾーン。
- 電子部品ゾーン。
- 電源配線ゾーン。
- ユーザー操作ゾーン。
- 保守ゾーン。

高温ゾーンは、ヒーター、高温の気流、温度センサー、その周辺部品です。

電子部品ゾーンは、コントローラ、ディスプレイ、低電圧センサー、ロジック配線です。

電源配線ゾーンは、電源、SSR、MOSFET、端子、ヒューズ、必要なら商用電源入力です。

ユーザー操作ゾーンは、手で触れるボタン、ハンドル、カバー、ディスプレイ、RFID リーダーの位置です。

これらのゾーンを無秩序に交差させないでください。

## 電子部品をヒーターのすぐ隣に置かない

コントローラ、ディスプレイ、DC-DC、配線は過熱に弱いです。

確保するもの:

- ヒーターとの距離。
- 空気の隙間。
- 必要なら遮熱板や仕切り。
- 電子部品の換気。
- 組み立て後に温度を確認できるアクセス。

電子部品が換気のない閉じたポケットにあると、ヒーターに直接触れていなくても過熱します。

## 必要な場所に空気を流す

ファンがあるだけでは気流は保証されません。

筐体は空気を次の経路へ導く必要があります。

- ヒーターを通す。
- スプールまたは作業ゾーンを通す。
- フィルタがある場合はフィルタを通す。
- 適切な位置のセンサーを通過させる。
- 設計どおり外へ出す、または循環させる。

悪い設計では、立派なファンがあっても有効な風量がほとんどありません。空気は抵抗の少ない隙間、フィルタの周囲、ヒーターの横を通ります。

エアダクトでは避けること:

- 急な絞り。
- 不要な曲がり。
- 細く長い通路。
- 開口面積の小さいグリル。
- 十分な静圧を持つファンなしのフィルタ。

## 実際のねじに合わせた固定部を作る

薄い柱にタッピングねじを入れれば永久に持つ、とは考えないでください。

分解する筐体では、次を使う方がよいです。

- 熱圧入インサート。
- ポケット内のナット。
- 適切な基板スタンドオフ。
- 標準サイズのねじ。
- 樹脂がへこむ場所のワッシャ。

印刷スタンドオフで重要なこと:

- 十分な直径。
- 丸みのある根元。
- 薄すぎない壁。
- 正しい印刷方向。
- 穴の周囲に十分な材料。

カバーを頻繁に開ける場合、樹脂ねじ山はすぐ摩耗します。

## 配線を擦らせない

筐体内の配線は固定する必要があります。

必要なもの:

- ケーブルチャンネル。
- 結束バンドの場所。
- ケーブル入口のストレインリリーフ。
- 鋭い角ではなく丸み。
- ファンとの隙間。
- ヒーターとの隙間。
- カバーで挟まれない保護。

悪い例は、外部ケーブルを引く力がそのまま端子や基板ピンにかかることです。

よい設計では、まず筐体がケーブルを固定し、その後でコネクタや端子へ届きます。

## 商用電源と低電圧を混ぜない

装置に 110-230V AC がある場合、筐体設計はずっと厳密にする必要があります。

最低限の考え方:

- 商用電源入力を分離する。
- ヒューズはアクセス可能だが保護されている。
- 商用電源端子は覆われている。
- 低電圧配線と商用電源配線を混ぜない。
- ユーザーが商用電源部に触れられない。
- 張力で配線が端子から抜けない。
- 樹脂が高温端子や電力部品に触れない。
- 必要な場所は接地する。

商用電源安全を「写真の真似」で作らないでください。商用電源部には、適切な端子、絶縁、ストレインリリーフ、ヒューズ、安全要件の理解が必要です。

## 保守のためのアクセスを残す

装置には保守が必要です。

アクセスを残すもの:

- ヒューズ。
- 端子。
- コントローラ。
- USB またはサービスコネクタ。
- 温度センサー。
- ファン。
- フィルタ。
- ヒーター。
- 取り付けねじ。

ファン交換に配線のはんだ外しやヒーター取り外しが必要なら、保守しやすい設計ではありません。

## 実際の温度で確認する

組み立て後は、部品が収まるかだけでは不十分です。

確認すること:

- 長時間運転後の電子部品温度。
- ヒーター付近の壁温度。
- 樹脂が軟化していないか。
- エアダクトが反っていないか。
- 端子が熱くなっていないか。
- 高温部との隙間が変わっていないか。
- 樹脂のにおいがしないか。
- 配線が高温面に触れていないか。

最初のテストは、すぐ電源を切れる状態で監視しながら行うのが安全です。

## 筐体を印刷する前のチェックリスト

印刷前に確認します。

1. 実部品をすべて測定した。
2. 基板、コネクタ、ケーブルの周囲に隙間がある。
3. 高温ゾーンが電子部品から分離されている。
4. 気流に明確な経路がある。
5. ファンを交換できる。
6. フィルタを交換できる。
7. 温度センサーを確認・再取り付けできる。
8. 配線が鋭い角を通らない。
9. 結束バンドやクリップの場所がある。
10. 商用電源配線が低電圧配線から分離されている。
11. カバーがケーブルを挟まない。
12. ねじとインサートの周囲に十分な樹脂がある。
13. 材料が動作温度に合っている。
14. 部品が変形しても装置が危険にならない。

## よくある間違い

- 先に見た目のよい箱を設計し、後から配線を押し込む。
- コネクタのスペースを残さない。
- 電源の換気を塞ぐ。
- コントローラを高温の隅に置く。
- 商用電源線と信号線を一緒に通す。
- ケーブルのストレインリリーフを用意しない。
- ねじ用に細いスタンドオフを使う。
- フィルタとファンに保守が必要なことを忘れる。
- 高温ゾーンの筐体を PLA で印刷する。
- 長時間加熱後に筐体を確認しない。

## 要点

- 筐体は実部品と配線を基準に設計します。
- 高温ゾーン、電子部品、電源配線、ユーザー操作ゾーンは分けます。
- 空気は「どこかに吹く」のではなく、有効な経路を通す必要があります。
- 配線は固定し、鋭い角、熱、張力から守ります。
- 商用電源は低電圧ロジックと混ぜてはいけません。
- 保守性は組み立て後ではなく、印刷前に計画します。
