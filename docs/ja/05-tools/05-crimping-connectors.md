# コネクタの圧着

圧着はワイヤーを端子またはコネクタに接続する方法で、はんだ付けは不要です。

良好な圧着は以下を提供します。

- 電気接触
- 機械的なワイヤー保持
- 絶縁サポート
- 再現性
- 便利なアセンブリとメンテナンス

不十分な圧着は熱くなり、分解され、ランダムエラーを引き起こし、ほぼ正常に見えます。

## はんだ付けより圧着が多くの場合より良い理由

コネクタと端子の場合、圧着ははんだ付けより優れていることが多いです。理由は以下の通りです。

- ワイヤーは柔軟なままです
- 接点は製造業者によって設計されます
- 絶縁は保持されます
- 関節は振動をより良く処理します
- コネクタを分解してサービスすることができます
- はんだ付け中にプラスチックコネクタボディが溶ける危険性はありません

はんだ付けはパッドとワイヤーに適していますが、製造業者が圧着を意図したコネクタの適切な接点に代わるべきではありません。

## 端子とコネクタの種類

シンプルなデバイスでは、以下がよく見られます。

- Dupont - ブレッドボードのための弱い信号接続
- JST-XH/JST-PHなど - センサー、ファン、小さなモジュール
- フェルール - スクリュー端子内の多素線ワイヤーのチップ
- Faston - いくつかの電力接続用のフラット端子
- リングと矛先の端子
- スクリュー端子
- ボード取り付け端子ブロック

各タイプには、独自の接点、独自のワイヤーゲージ、独自のツールが必要です。

## 適切なツールが必要です

ペンチは圧着ツールではありません。

接点を握ることができるので、それは保持しているように見えます。しかし、適切な圧着は得られません。

良好な圧着のためには、以下が必要です。

- 正しいワイヤーゲージ用の端子
- 正しいストリップ長
- 正しいツールマトリックス
- マトリックス内の正しい接点位置
- 素線と絶縁圧着用の分離されたゾーン
- 破損した素線はありません

専門的なコネクタ製造業者は、圧着仕様、圧着高さ、ストリップ長、引張力を提供しています。DIYアセンブリの場合、完全な制御がない場合もありますが、原則は同じです。接点、ワイヤー、ツールは相互に一致する必要があります。

## オープンバレル圧着

JSTやDupontのような多くの小さな接点には、2つのペアの「翼」があります。

- 1つのペアは裸の導体を圧着します
- もう1つのペアは絶縁を保持します

良い結果。

- 導体は正しいゾーンに見えます
- 絶縁は後部の翼で保持されます
- 露出した長さが長すぎない
- 導体の素線は突き出ていない
- 接点がゆがんでいない
- 接点はコネクタボディに入り、所定の位置にロックされます

絶縁が導体圧着ゾーンに入った場合、電気接触が悪くなります。

導体だけが圧着され、絶縁が保持されない場合、ワイヤーが移動するとき、ワイヤーが破断することがあります。

## フェルール

スクリュー端子内の多素線ワイヤーの場合、フェルールがしばしば役立ちます。

彼らは。

- すべての素線を一緒に集める
- 素線の分離を防ぐ
- 端子内のシートを改善する
- いくつかの素線が外に残る危険性を減らす
- 関節をより整理する

これは特に電力ワイヤー、端子ブロック、およびサービスされるアセンブリに役立ちます。

しかし、フェルールもワイヤーゲージに合致し、右のマトリックスで圧着される必要があります。

## 圧着の確認方法

圧着後に確認してください。

- 接点はワイヤーに動きません
- 絶縁が保持されます
- 導体は引き抜かれません
- 素線は切られていない
- 露出された長さが長すぎない
- 接点はコネクタボディに入ります
- ロックが所定の位置にクリックされます
- ワイヤーはそっと引くことに耐えます

やさしい引きテストは役に立ちます。慎重にワイヤーを引きます。接点から出てきてはいけません。

すべての力で引く必要はありません。目的は、インストール前に明らかに悪い圧着を見つけることです。

## なぜ不十分な圧着が熱くなるか

不十分な圧着は高い抵抗を生成します。

電流下で、これは熱になります。

まず、ターミナルは暖かいかもしれません。その後、プラスチックが暗くなり、接触が悪くなり、熱が増加します。

これは特に危険です。

- ヒーター
- 有意な電流を持つファン
- LEDストリップ
- 電源
- SSR/MOSFETサーキット
- 商用接続

ターミナルが熱くなった場合は、電源をオフにして接続をやり直してください。

## Dupontは電力用ではありません

Dupontはブレッドボードと弱い信号に便利です。

ただし、以下のための適切な電力コネクタとして使用することはできません。

- ヒーター
- デバイスパワー
- 強力なLEDストリップ
- 商用部品
- 大電流を持つモーターまたはサーボ

コネクタが物理的にピンに適合していても、それは必要な電流、振動、熱に対して定格されていることを意味しません。

## 一般的なエラー

- ペンチで圧着
- 間違ったゲージ端子を選択
- 絶縁をはがしすぎ
- 絶縁を剥離
- 導体ではなく絶縁を圧着
- 絶縁サポートを圧着していない
- いくつかの素線を切る
- 接点がボディ内でロックされていない
- Dupontで保持されている電源ライン
- 間違ったフェルールゲージ
- 引きテストをしなかった
- ターミナルが熱いがデバイスが実行し続ける

## 重要な点

- 圧着は電気接触と機械的保持の両方です
- 接点、ワイヤー、ツールは相互に一致する必要があります
- ペンチは圧着ツールに置き換わりません
- スクリュー端子内の多素線ワイヤーの場合、フェルールがしばしば役立ちます
- 不十分な圧着は熱くなり、危険です
- 電力部品は弱いブレッドボードコネクタに依存してはいけません
