# はんだ付け

はんだ付けは、ワイヤーをパッドに確実に接続し、コネクタをはんだ付けし、破損した接続を修復し、または小さなモジュールを組み立てるときに使用されます。

ただし、はんだ付けは、ワイヤーが引き、振動するか加熱される場所での適切なコネクタ、端子、または機械的締め具に代わるべきではありません。

## はんだ付けが適切な場合

はんだ付けは以下に適しています。

- ボードへのワイヤーのはんだ付け
- ピンヘッダーのインストール
- 破断ワイヤーの修復
- 小さなモジュールの接続
- サーミスタまたは信号ワイヤーのはんだ付け
- プロトタイプアセンブリ

はんだ付けは以下には最適な選択肢ではありません。

- 頻繁に分解される接続
- ひずみ緩和のない電力端子
- 移動するワイヤー
- ホットゾーン内の接続で保護なし
- 適切な端子と囲いのない商用110-230V AC部品

## 最小限のキット

適切なはんだ付けの場合、以下が必要です。

- 温度制御付きはんだこて
- はんだ
- フラックス
- はんだこてスタンド
- スポンジまたは真鍮線でチップを清掃
- ワイヤーカッター
- ワイヤーストリッパー
- ピンセットまたは第3の手
- 熱収縮チューブ
- 必要に応じてクリーニング用イソプロピルアルコール

スタンドのないはんだこては悪い考えです。ホットチップは簡単に手、ワイヤー、囲い、またはテーブルを焼きます。

## ワイヤーをティン

ワイヤーのティンは、露出した素線を薄いはんだ層でコーティングすることを意味します。

手順。

1. 絶縁を少し剥きます。
2. ワイヤーが多重素線の場合は、素線をねじり合わせます。
3. はんだが流れが悪い場合はフラックスを塗布します。
4. はんだこてでワイヤーを加熱します。
5. 加熱された領域にいくつかのはんだを塗布します。
6. はんだが素線全体に流れるようにします。

ワイヤー端を太くて硬い塊に変えないでください。ティンはきれいで薄くする必要があります。

## ワイヤーをパッドにはんだ付け

手順。

1. ボードとワイヤーを固定します。
2. パッドをティンします。
3. ワイヤーをティンします。
4. ワイヤーをパッドに塗布します。
5. ワイヤーとパッドを同時に加熱します。
6. はんだが溶けて部品を結合するようにします。
7. はんだを削除し、その後にアイロンを削除します。
8. はんだが冷めている間、関節を動かさないでください。

良好なはんだジョイントは滑らかで光沢があるか、はんだに応じて均等にくすんでいます。パッドの上に座っているスプロブではなく、パッドを濡らしていないはずです。

## コールドはんだジョイント

コールドはんだジョイントは、はんだが適切に加熱されず、正常に流れなかった場合です。

兆候。

- 粗い表面
- 塊のはんだ
- ワイヤーが移動する
- 接触が来たり行ったり
- わずかな動きで破損する接合

コールドはんだジョイントは危険です。時々働く場合があります。加熱されたまたは振動デバイスでは、そのような接触が劣化します。

通常、コールドジョイントはフラックスで再加熱して修復され、はんだが適切に流れるまで繰り返します。

## 過熱パッド

パッドを長く加熱しすぎた場合、ボードから浮上することができます。

これは特に影響します。

- 安いモジュール
- 小さなパッド
- 薄いトレース
- 複数の修復試行
- パッドにワイヤーを引く

はんだが流れない場合、常に長く加熱する必要があるわけではありません。多くの場合、フラックスを追加し、チップをクリーニングし、正しい温度またはより大きなチップを使用すると役立ちます。

## フラックス

フラックスははんだが金属を濡れるのに役立ちます。

フラックスなしでは、はんだはしばしば丸くなり、部品をよく結合しません。

はんだ付け後、一部のフラックスは洗浄が必要です。これはフラックスタイプに依存します。

- ノークリーンはしばしば残すことができます
- 水溶性は除去する必要があります
- アクティブフラックスはボード上に残してはいけません

フラックスタイプが不明な場合は、電子グレードのフラックスを使用して説明を読んでください。

## 熱収縮と絶縁

はんだ付けされた関節は絶縁される必要があります。

ワイヤーの場合、通常は熱収縮チューブが使用されます。

手順。

1. はんだ付けする前にワイヤー上で熱収縮をスライドさせます。
2. ワイヤーをはんだ付けします。
3. 関節を確認します。
4. 熱収縮を所定の位置にスライドさせます。
5. そっと加熱します。

はんだ付けされた関節を、囲い、別のワイヤー、端子、またはファンに触れる可能性がある場所に露出させたままにしないでください。

## ひずみ緩和

はんだは機械的応力が好きではありません。

ワイヤーが引く、振動、または移動する場合は、ひずみ緩和が必要です。

- ケーブルタイ
- クランプ
- ひずみ緩和コネクタ
- 安全な場所のシリコンブロブ
- 囲いに固定されたワイヤー
- 直接はんだ付けの代わりにコネクタ

悪い慣行。ワイヤーははんだパッドでのみ保持されます。時間がたつと、パッドを緩く引き裂くことができます。

## パワーワイヤー

パワーワイヤーはいばんだ付けされ、特に注意が必要です。

確認してください。

- ワイヤーは正しいゲージを持ちます
- 関節は完全に加熱されます
- コールドはんだジョイントはありません
- 露出した素線はありません
- 絶縁が存在します
- 機械的締め具が存在します
- 関節は保護なしでホットゾーンの隣にはありません

電力線の場合、適切な端子またはコネクタはしばしばワイヤーを永久にはんだ付けするより優れています。

## はんだ付け後に確認すること

はんだ付け後。

- 関節を検査する
- 隣接する接点が短絡していないことを確認します
- マルチメーターを使用して必要な接続を確認してください
- `+` と `GND` の間の短絡がないことを確認してください
- ワイヤーをそっと引きます
- 熱収縮が金属をカバーしていることを確認してください
- ワイヤーがパッドを引かないことを確認してください

## 一般的なエラー

- 汚れたチップでのはんだ付け
- フラックスを使用していない
- パッドとワイヤーではなく、はんだだけを加熱
- はんだブロブを作成
- はんだが冷めている間にワイヤーを移動
- パッドを過熱
- 熱収縮のない開いた関節を残す
- はんだだけでワイヤーを保持
- はんだこてが弱い電力ワイヤーが薄い
- 電子機器用ではないアクティブフラックスを使用

## 重要な点

- 良好なはんだ付けには、はんだをドリップするだけでなく、両方の部品を加熱する必要があります
- フラックスはしばしば不十分な濡れの問題を解決します
- コールドはんだジョイントは時々働く可能性があるため危険です
- はんだ付けされた関節は絶縁され、機械的に軽減される必要があります
- 頻繁に分解され、電力接続の場合、コネクタまたは端子はしばしばワイヤーを永久にはんだ付けするより優れています
