# フィラメント乾燥機の自作をどこから始めるか

フィラメント乾燥機、プリンター用加熱チャンバー、または独立した加熱モジュールを作りたい場合は、ここから始めてください。このページでは、資料の読み進め方と、部品を買う前に決めるべきことを説明します。

あなたは既に3Dプリンタで印刷しており、フィラメントドライヤーを構築したいと考えています。しかし、回路図を開くとすぐに質問が現れます。どの電源を選ぶべきか、グラウンドはどこに接続するのか、MOSFETかSSRか、なぜヒートシンクが必要なのか。このセクションはこれらの質問に段階的に答えます。最初の電流計算から動作するデバイスまで。

このセクションの後、あなたは何を構築しているのか、なぜこのようにするのか、どこに危険があるかを理解し、デバイスに電源を入れる前にそれを確認する方法を知るでしょう。

セクションは徐々に単純な概念から実際の結果へと導きます。

ここでのパスは単純から複雑へ進みます：

1. 最初に電力、電流、負荷、および基本的な安全性を理解します。
2. 次にどのようなコントローラが存在し、どれを選ぶべきかを把握します。
3. 次に基本的なコンポーネント（ヒーター、ファン、センサー、ディスプレイ、RFIDおよびロードセル）を理解します。
4. 次に最小限のツール（マルチメータ、USB-UART、はんだごて、圧着工具）の使用方法を学びます。
5. 次に実用的な接続に移ります。
6. 次にエンクロージャと3Dプリント部品について考えます。
7. 最後に、一般的な間違いと診断チェックリストを手元に用意します。

主な考え方：

電子工学のすべてを一度に理解する必要はありません。ステップバイステップで進み、毎回次の小さなステップを理解することで十分です。

このセクションが提供すべきもの：

- 低電圧の`12V`/`24V DC`回路と商用電源`110-230V AC`がどのように異なるかについての理解；
- 負荷電流をおおよそ計算する能力；
- MOSFETやSSRまたはリレーが必要な時期についての理解；
- ESP32、Arduino、RP2040およびSTM32が実際にどのように異なるかについての理解；
- Klipper MCUの場合、RP2040またはSTM32を検討する方が良い理由についての理解；
- センサー、ファン、ヒーター、およびディスプレイについての基本的な理解；
- 最小限のマルチメータ診断スキル；
- どの印刷部品が熱の近くに配置できるかについての理解；
- 繰り返さない方がよい間違いのリスト。

このセクションが行わないこと：

- `110-230V AC`を使用する場合、電気技士に代わるものではありません；
- 深い回路設計を教えません；
- すべての物理を説明しようとはしません；
- 安全を理解することなく危険なデバイスを組み立てる許可を与えません。

読み方：

- トピックが新しい場合は、順に進みます；
- 既にデバイスを構築している場合は、必要なセクションをリファレンスとして開きます；
- デバイスが機能しない場合は、まず`08-common-mistakes`を参照してください；
- `110-230V AC`を使用する場合は、まず安全、SSR、ワイヤー、端子、および保護接地に関するすべてを読んでください。
