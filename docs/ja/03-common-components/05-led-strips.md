# LED ストリップ

LED ストリップは、LED と電力トレースを備えたフレキシブルボードです。プリンター、ドライヤー、小さな DIY デバイスでは、通常、チャンバー照明、ステータス表示、作業エリア照明、または装飾的なエンクロージャー照明に使用されます。

初心者の主な間違いは、LED ストリップを小さな LED のように扱うことです。短いストリップであっても、ファンより多くの電流を引き出すことができ、長いストリップは完全な電力ロードになります。

## どこで使用されているか

3D プリンターの周りの DIY デバイスでは、LED ストリップは以下に便利です:

- プリンターチャンバーの照明;
- フィラメント乾燥機の照明;
- ステータス表示: 加熱、乾燥、エラー、待機;
- エンクロージャー内の作業エリア照明;
- メインライトなしの柔らかい夜間照明;
- プリント終了またはエラーが発生した場合の視覚的信号。

サービス照明の場合、シンプルな白いストリップが通常より良いです。モード表示の場合、RGB またはアドレス指定可能なストリップは便利ですが、電力と制御がより複雑です。

## 電圧: 5V、12V、または 24V

LED ストリップはさまざまな電圧で提供されます:

- `5V` - WS2812/NeoPixel のようなアドレス指定可能なストリップがよくあります;
- `12V` - 一般的な白および RGB ストリップ;
- `24V` - より長いセクションと 24V システムに便利。

ストリップ電圧は電源と一致する必要があります。`12V` ストリップを `24V` に接続することはできません。`12V` の `24V` ストリップは暗くなるか機能しないことがあります。`12V` または `24V` の `5V` ストリップはほぼ確実に損傷します。

プリンターすでに `24V` を持っている場合、そのストリップをそれに接続できることを意味しません。正確に `24V` ストリップを購入するか、正しい電圧の DC-DC コンバーターを入れます。

## 通常およびアドレス指定可能なストリップ

LED ストリップには 2 つの主なタイプがあります。

通常のストリップは一度に点灯します。これは:

- 単一色の白;
- 暖かい/冷たい白;
- 長さ全体で色を変える RGB ストリップ;
- 別の白チャネル付き RGBW ストリップ。

このようなストリップは各 LED に マイクロチップがありません。明度は MOSFET、LED コントローラー、または適切なボード出力を通じたパワースイッチング または PWM で制御されます。

アドレス指定可能なストリップには、個々の LED または LED グループ用の制御マイクロチップがあります。異なるセクションを異なる色で照らすことができます。典型的な例: WS2812B、SK6812、NeoPixel 互換ストリップ。

アドレス指定可能なストリップが必要です:

- 正しい電圧での電力;
- 制御器との共通 `GND`;
- データワイヤ `DIN`;
- ストリップ上の矢印に沿った正しいデータ方向;
- しばしば - 5V データ信号レベル;
- 大きなドロップなしで慎重な電力。

シンプルなチャンバー照明の場合、アドレス指定可能なストリップは通常、過剰です。素敵な表示と効果の場合、便利ですが、より多くの電力への注意が必要です。

## 電流と電力

LED ストリップを色と長さだけで選択しないでください。その電力を知る必要があります。

製品ページは通常、以下をリストしています:

- 電圧: 例えば `12V` または `24V`;
- メートルあたりの電力: 例えば `4.8 W/m`、`9.6 W/m`、`14.4 W/m`;
- メートルあたりの LED 数;
- LED タイプ: 例えば `3528`、`5050`、`2835`;
- ストリップ幅;
- 保護度: むき出し、シリコン ジャケット、IP65/IP67;
- セクションあたりの最大長。

電流は単純に計算されます:

```text
電流 = 電力 / 電圧
```

例: `9.6 W/m` の電力で `24V` ストリップの `2 m` があります。

```text
総電力 = 2 m × 9.6 W/m = 19.2 W
電流 = 19.2 W / 24 V = 0.8 A
```

このようなストリップでは、電源、MOSFET、ワイヤ、コネクタは `0.8 A` 以上に快適に対応する必要があります。実際には、特にストリップが長期間実行される場合、少なくとも `30-50%` のマージンを追加する方が良いです。

RGB ストリップでは、すべてのチャネルの最大電流を考慮する必要があります。RGB で白は通常、赤、緑、青チャネルが同時にオンになることを意味します。

アドレス指定可能な 5V ストリップでは、フルホワイト時に RGB ピクセルあたり約 `60 mA` の大まかな見積もりです。実際の効果では、電流が少なくなることができますが、「通常、フルブライトネスではない」ために、電源とワイヤリングのサイズを設定することはできません。

## GPIO からストリップに電源を供給できない理由

制御器の GPIO は信号出力であり、電源ではありません。

LED ストリップを直接マイクロコントローラー ピンに接続することはできません。GPIO はストリップ電流に対して定格されていません。これはボード、再起動、不安定な操作、またはトレース過熱を損傷することができます。

正しいロジック:

- ストリップ電流は電源から来ます;
- 制御器は オン/オフ、明度、またはデータのみを管理します;
- MOSFET、LED ドライバー、LED コントローラー、またはボード電力出力がパワースイッチングを処理します;
- 制御信号がある場合、制御器と電源グラウンドが接続されています。

## シンプルな単色ストリップの接続

白 `12V` または `24V` ストリップの場合、ローサイド MOSFET がよく使用されます: ストリップのプラスが電源プラスに接続され、ストリップのマイナスは MOSFET モジュールで切り替えられます。

典型的なサーキット:

1. 電源 `+V` は LED ストリップ `+` に行きます。
2. LED ストリップ `-` は MOSFET モジュール電力出力に行きます。
3. 電源 `GND` は MOSFET モジュールに行きます。
4. 制御器 `GND` が電源 `GND` に接続されます。
5. 制御器制御ピンが MOSFET モジュール入力に行きます。

プリンター ボードがファンまたは LED 用の管理された出力を既に持っている場合、必要な電圧と電流に対して定格されている場合にのみ使用できます。出力制限をチェックせずに、長いストリップをランダムなコネクタに接続することはできません。

## RGB ストリップ

典型的な RGB ストリップは通常、共通のプラスと 3 つの管理されたマイナスを持っています:

- `+V`;
- `R`;
- `G`;
- `B`。

各カラー チャネルは、別個の MOSFET チャネルまたは既成の RGB コントローラーが必要です。RGB ストリップ全体用の 1 つの MOSFET は、色を変更できるだけです。

RGB ストリップ用 MOSFET モジュールを選択する場合、チャネルあたりの電流と総電流を見てください。コネクタ、ターミナル、ワイヤもロードを処理する必要があります。

## アドレス指定可能なストリップ

アドレス指定可能なストリップは通常、次を持っています:

- `+5V` または他の電力(5V モデルでない場合);
- `GND`;
- `DIN` - データ入力;
- 時々 `DOUT` - 次のセクションへのデータ出力。

重要なルール:

- データをストリップ上の矢印に接続します;
- 制御器とストリップは共通接地を持つ必要があります;
- 3.3V 制御器の 5V アドレス指定可能なストリップでは、レベルコンバーターが必要になることがあります;
- 長いストリップの前に、電力を横切った電解コンデンサが便利です;
- `300-500 Ohm` 抵抗はしばしば、ストリップ入力近くのデータライン内に配置されます;
