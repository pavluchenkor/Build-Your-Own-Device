# 万用表

万用表是主要的第一线诊断工具。

你可以用它检查：

- 电源是否存在；
- 电压是否正确；
- 正极和负极在哪里；
- 电线是否断裂；
- 保险丝是否完好；
- 热敏电阻是否似乎功能正常；
- 在负载下是否有电压下垂。

但是如果你混淆了模式，很容易用万用表犯错。最危险的错误涉及测量电流和主电压。

## 探针和端口

万用表通常有：

- `COM` - 公共端口，几乎总是插入黑色探针；
- `V/Ohm/mA`或类似端口 - 用于电压、电阻、连续性和小电流；
- `10A`或`A` - 用于大电流的单独端口。

测量前，始终检查：

- 红色探针插入哪个端口；
- 选择了什么模式；
- 你究竟要测量什么。

一个非常常见的错误：测量电流后，你忘记将探针从`A`移回`V/Ohm`，然后尝试测量电压。这可能导致短路。

## 测量直流电压

直流是直接（恒定）电压。在我们的设备中，这通常是：

- `3.3V`；
- `5V`；
- `12V`；
- `24V`。

程序：

1. 黑色探针插入`COM`。
2. 红色探针插入`V`端口。
3. 选择直流电压模式：通常`V`带有直线。
4. 黑色探针放在负极或`GND`。
5. 红色探针放在正极。
6. 读取显示屏。

如果显示屏上的数字前出现负号，探针交换了。这很有用：你可以用这种方式确定极性。

## 在何处测量电压

不要将自己限制在电源输出。

检查：

- 在电源终端；
- 在板输入；
- 在负载终端；
- 在直流-直流模块；
- 在风扇上；
- 在伺服上；
- 在LED条带上。

如果电源显示24V，但负载显示明显较少，请在电线、终端或连接器上查找下垂。

对于电源诊断，重要的是在负载下测量，而不仅仅是空转。

## 测量交流电压

交流是交流电压，例如来自主电源的110-230V。

主电压很危险。

如果你不理解自己在做什么，不要用万用表测量开放的主电源部分。最好使用现成的安全模块、密闭终端和专家帮助。

如果你确实测量，你需要：

- 一个具有安全等级**CAT II**或**CAT III**的万用表 — 这写在设备本体上，靠近电压，例如`CAT II 600V`。CAT I不适合家用主电源。CAT III和CAT IV为更复杂的安装提供额外的边距；
- 正常工作的探针，等级不低于万用表；
- 干燥的手；
- 密闭和稳定的组装；
- 理解相位和中性线在哪里；
- 没有意外的开放接触点。

对于大多数涉及低电压电子产品的任务，直流测量是足够的。

## 连续性检查

连续性显示两点是否电连接。

检查很有用：

- 如果电线完好；
- 如果`GND`已连接；
- 如果电缆未断裂；
- 如果按钮有效；
- 如果保险丝完好；
- 相邻接触点是否短路。

程序：

1. 关闭电源。
2. 将万用表设置为连续性模式：通常是声音图标或二极管符号。
3. 将探针彼此触摸 - 应该有嗡声。
4. 触摸要检查的两个点。
5. 如果发出嗡声，这些点之间有导电连接。

连续性检查在断电电路上进行。

## 电阻

电阻以欧姆为单位测量。

对于我们的任务，这是必要的：

- 检查热敏电阻；
- 检查断线；
- 检查保险丝；
- 确定是否存在短路；
- 检查电阻器。

重要：电阻仅在断电电路上测量。

如果你在通电的电路板上测量电阻，你可能会得到不正确的读数或损坏万用表。

## 测试热敏电阻

对于典型的NTC`100K`在室温下，预计数十或约`100 kOhm`。

如果万用表显示：

- `OL`或无穷大 - 可能是开路；
- 几乎`0 Ohm` - 可能是短路；
- 当你移动电线时值波动很大 - 接触不良；
- 当被手指加热时电阻减小 - 看起来像活跃的NTC。

确切的值取决于热敏电阻类型和温度。

## 测量电流

测量电流比测量电压更危险。

电压并联测量：探针接触两个点。

电流是串联测量：你必须破坏电路并将万用表连接进去，以便电流流过设备。

错误 - 将万用表置于电流模式，并将探针触摸到电源的正极和负极。那几乎是通过万用表的短路。

对于初学者，最好是：

- 首先从功率计算电流；
- 使用现成的瓦特表/USB功率表/直流功率表；
- 仅当你理解如何将万用表串联连接时才测量电流；
- 从正确的范围和正确的端口开始。

## 检查保险丝

检查断电电路上的保险丝。

方法：

- 连续性；
- 电阻测量。

好的保险丝通常显示连续性并具有非常低的电阻。

烧断的保险丝通常不显示连续性。

如果保险丝吹断，你不能只安装更高额定值的保险丝。首先找到原因。

## 如何不烧毁万用表

最低规则：

- 测量前检查模式；
- 测量前检查红色探针端口；
- 不要在通电电路上测量电阻；
- 不要像测量电压那样测量电流；
- 不要在不理解安全的情况下进入110-230V交流电；
- 如果万用表不是自动量程，请从更高的范围开始；
- 使用工作探针；
- 不要用手指触摸金属尖端。

## 实际场景

检查24V电源：

1. 直流电压模式。
2. 黑色探针放在负极。
3. 红色探针放在正极。
4. 应该读约24V。

检查风扇：

1. 在风扇连接器上测量电压。
2. 检查极性。
3. 检查启动时的电压。

检查断线：

1. 断开电源。
2. 连续性模式。
3. 探针在电线的两端。
4. 没有嗡声 - 可能是开路。

检查`+`和`GND`之间的短路：

1. 断开电源。
2. 检查`+`和`GND`之间的连续性。
3. 如果在不应该的地方发出嗡声，请寻找短路。

## 要点

- 对于直流电压，使用带有直线的`V`模式。
- 电阻和连续性仅在断电电路上进行。
- 电流是串联测量，而不是并联。
- 测量电流后，将探针从`A`移回正常的`V/Ohm`端口。
- 主电压很危险；在不理解安全的情况下不要测量开放的110-230V部分。
- 负载下的万用表常常会发现空转时看不见的问题。
