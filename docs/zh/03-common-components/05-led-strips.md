# LED 灯带

LED 灯带是带有 LED 和电源迹线的柔性板。在打印机、干燥机或小型 DIY 设备中，它通常用于腔室照明、状态指示、工作区照明或装饰性机箱照明。

初学者的主要错误是把 LED 灯带当作小 LED。即使是短灯带也可能吸取比风扇更多的电流，长灯带变成全功率负载。

## 用途

在 3D 打印机周围的 DIY 设备中，LED 灯带对以下用途很有用：

- 照亮打印机腔室；
- 照亮灯丝干燥机；
- 状态指示：加热、干燥、错误、等待；
- 机箱内的工作区照明；
- 不含主光的软夜间照明；
- 打印完成或错误发生时的视觉信号。

对于维修照明，简单的白色灯带通常更好。对于模式指示，RGB 或可寻址灯带很方便，但在电源和控制方面更复杂。

## 电压：5V、12V 或 24V

LED 灯带有不同的电压：

- `5V` - 通常是可寻址灯带，如 WS2812/NeoPixel；
- `12V` - 常见的白色和 RGB 灯带；
- `24V` - 对于较长的部分和 24V 系统很方便。

灯带电压必须与电源匹配。你不能将 `12V` 灯带连接到 `24V`。`24V` 灯带在 `12V` 上可能变暗或不工作。`5V` 灯带在 `12V` 或 `24V` 上几乎肯定会被损坏。

如果你的打印机已经是 `24V`，这并不意味着任何灯带都能连接到它。你需要购买确切的 `24V` 灯带或放置适当电压的 DC-DC 转换器。

## 常规和可寻址灯带

有两种主要的 LED 灯带类型。

常规灯带同时亮起。这可能是：

- 单色白；
- 暖/冷白；
- 沿其整个长度改变颜色的 RGB 灯带；
- 具有单独白色通道的 RGBW 灯带。

这样的灯带在每个 LED 上没有微芯片。亮度通过电源开关或通过 MOSFET、LED 控制器或合适的板输出的 PWM 控制。

可寻址灯带为每个 LED 或 LED 组有控制微芯片。它让你点亮不同颜色的不同部分。典型例子：WS2812B、SK6812、NeoPixel 兼容灯带。

可寻址灯带需要：

- 正确电压的电源；
- 与控制器共享的 `GND`；
- 数据线 `DIN`；
- 沿灯带上的箭头的正确数据方向；
- 通常 - 5V 数据信号电平；
- 小心的电源，无大压降。

对于简单的腔室照明，可寻址灯带通常过度。对于漂亮的指示和效果，它很方便，但需要更多关注电源。

## 电流和功率

选择 LED 灯带不仅仅是按颜色和长度。你需要知道它的功率。

产品页面通常列出：

- 电压：例如 `12V` 或 `24V`；
- 每米功率：例如 `4.8 W/m`、`9.6 W/m`、`14.4 W/m`；
- 每米 LED 数量；
- LED 类型：例如 `3528`、`5050`、`2835`；
- 灯带宽度；
- 保护等级：裸露、硅胶夹克、IP65/IP67；
- 每个部分的最大长度。

电流计算很简单：

```text
电流 = 功率 / 电压
```

例子：你有 `2 m` 的 `24V` 灯带，功率为 `9.6 W/m`。

```text
总功率 = 2 m × 9.6 W/m = 19.2 W
电流 = 19.2 W / 24 V = 0.8 A
```

对于这样的灯带，电源、MOSFET、线和连接器必须轻松处理超过 `0.8 A`。实际上，最好添加至少 `30-50%` 的裕度，特别是如果灯带长期运行。

对于 RGB 灯带，你必须计算所有通道的最大电流。RGB 上的白通常意味着红、绿和蓝通道同时打开。

对于可寻址 5V 灯带，粗略估计在全白时每个 RGB 像素最多 `60 mA`。在实际效果中，电流可能较少，但你不能为"通常不是全亮度"的电源和接线调整大小。

## 为什么你不能从 GPIO 为灯带供电

控制器的 GPIO 是信号输出，不是电源。

你不能直接将 LED 灯带连接到微控制器引脚。GPIO 的额定值不是针对灯带电流。这可能损坏板、导致重启、不稳定操作或迹线过热。

正确的逻辑：

- 灯带电流来自电源；
- 控制器仅管理开/关、亮度或数据；
- MOSFET、LED 驱动器、LED 控制器或板电源输出处理电源开关；
- 如果有控制信号，控制器和电源接地连接。

## 连接简单的单色灯带

对于白色 `12V` 或 `24V` 灯带，通常使用低端 MOSFET：灯带的加号连接到电源加号，灯带的减号由 MOSFET 模块开关。

![LED 灯带与 SMD 二极管的特写](../../img/03-common-components/05-led-strip-closeup.jpg)

*来源: [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:LED_strip_closeup.jpg), Akbermamps, CC BY 4.0*

典型电路：

1. 电源 `+V` 连接到 LED 灯带 `+`。
2. LED 灯带 `-` 连接到 MOSFET 模块电源输出。
3. 电源 `GND` 连接到 MOSFET 模块。
4. 控制器 `GND` 连接到电源 `GND`。
5. 控制器控制引脚连接到 MOSFET 模块输入。

如果打印机板已经有风扇或 LED 的管理输出，你只能在它的额定值与所需电压和电流相符时使用它。你不能在不检查输出限制的情况下将长灯带连接到任何随机连接器。

## RGB 灯带

典型的 RGB 灯带通常具有公共加号和三个管理的减号：

- `+V`；
- `R`；
- `G`；
- `B`。

每个颜色通道需要单独的 MOSFET 通道或现成的 RGB 控制器。一个整个 RGB 灯带的 MOSFET 只能打开和关闭它，不能改变颜色。

为 RGB 灯带选择 MOSFET 模块时，查看每个通道和总电流。连接器、端子和线也必须处理负载。

## 可寻址灯带

可寻址灯带通常具有：

- `+5V` 或其他电源（如果不是 5V 型号）；
- `GND`；
- `DIN` - 数据输入；
- 有时 `DOUT` - 数据输出到下一部分。

重要规则：

- 向灯带上的箭头方向连接数据；
- 控制器和灯带必须有公共地；
- 对于 3.3V 控制器上的 5V 可寻址灯带，你通常需要电平转换器；
- 在长灯带之前，跨电源的电解电容很有用；
- 约 `300-500 欧` 的电阻通常放在靠近灯带输入的数据线中；
- 对于长灯带，最好不仅在开始时供电，还在其他地方供电。

如果可寻址灯带从单独的电源供电，你不能仅应用 `DIN` 而没有公共 `GND`。数据信号然后没有适当的参考电平，灯带会随机闪烁或不工作。

## 压降和多点电源

长 LED 灯带在开始处可能很亮，在末端明显变暗。这不是"坏控制器"，它是线和灯带的铜迹上的压降。

电压越低，电流越高，问题越糟。所以 `5V` 和 `12V` 灯带比相同功率的 `24V` 灯带更常需要从多点供电。

压降的迹象：

- 灯带末端较暗；
- RGB 上的白色变为黄色或红色；
- 可寻址灯带在明亮效果期间闪烁；
- 当亮度增加时控制器重启；
- 线、连接器或灯带开始变热。

解决方案：

- 在适当的电压下使用灯带；
- 使用足够规格的线；
- 将电源应用到长部分的开始和结束；
- 将长灯带分成部分；
- 在电源线上使用保险丝；
- 不要通过弱连接器或薄迹线路由所有电流。

## 热量和安装

LED 灯带本身产生热量。对于硅胶夹克中的亮灯带和安装在密闭机箱内的灯带，这特别显著。

不良的安装位置：

- 靠近加热器；
- 在热腔室内的软 PLA 上；
- 在不散热的表面上；
- 灯带接触移动部件的地方；
- 在经常不用连接器移除的盖上。

为了长期寿命，最好将灯带安装在铝型材或其他散热的表面上。如果灯带在打印机腔室内，请说明腔室温度和粘合剂层温度。

## 购买前的检查清单

购买 LED 灯带前，检查：

- 灯带电压；
- 每米功率；
- 总长度；
- 颜色：白、RGB、RGBW、可寻址；
- 控制类型；
- 灯带宽度和安装位置；
- 安装位置温度；
- 你是否需要铝型材；
- 你是否需要 MOSFET 模块或 LED 控制器；
- 电源是否可以处理额外负载；
- 是否有维修用的适当连接器。

对于打印机腔室，如果整个系统已经是 `24V`，`24V` 白色灯带通常更实用。对于小型 ESP32 指示器，短的 `5V` 可寻址灯带可能很方便。对于长的装饰性 RGB 照明，最好提前计算电流并考虑多点电源。

## 典型错误

- 将灯带连接到错误的电压；
- 从 GPIO 为灯带供电；
- 没有为整个长度计算电流；
- 在没有裕度的情况下选择 MOSFET 模块；
- 用薄线连接长灯带；
- 忘记了控制器和灯带之间的公共地；
- 将可寻址灯带数据连接到 `DOUT` 而不是 `DIN`；
- 在需要时没有为来自 3.3V 控制器的 5V 可寻址灯带安装电平转换器；
- 仅在长灯带的一端供电；
- 在热区安装灯带而不检查温度；
- 在可移除的盖上留下灯带而不连接器。

## 主要点

LED 灯带不是信号 LED，它是负载。首先检查电压和功率，然后计算电流，选择线、MOSFET 或控制器，最后才连接到板。

对于简单照明，在系统电压下选择常规白色灯带。对于效果和指示，你可以使用可寻址灯带，但电源、公共地、信号电平和压降保护特别重要。
