# 伺服馬達

伺服馬達是一個小驅動器，具有馬達、齒輪箱和內部電子設備。你給它一個位置，它試圖將軸旋轉到該位置並保持它。

在簡單的設備中，伺服馬達在你需要不只是開啟馬達，而是將機構旋轉到可理解的角度的地方很方便：打開擋板、轉移鎖、按下按鈕、轉換氣流或旋轉小指示旗。

## 應用場景

在 iDryer 類設備和 3D 印表機周邊設備中，伺服馬達可用於：

- 空氣進出口擋板；
- 空氣風道轉換；
- 打開/關閉小蓋子；
- 機械鎖；
- 按下物理按鈕；
- 移動指示旗；
- 簡單的計量或捕捉。

伺服馬達對於光學機械和有限的旅程很好。對於風扇、螺釘或泵的連續旋轉，它通常不工作：你需要不同的馬達和驅動器。

## 三根線

典型的業餘伺服馬達有三根線：

- 電源：通常 `4.8-6V`，有時特殊型號上為 `7.4V` 或其他值；
- 接地：`GND`；
- 信號：來自控制器的控制脈衝。

常見的線路顏色：

- 紅色 - 電源；
- 黑色或棕色 - 接地；
- 黃色、橙色或白色 - 信號。

你無法盲目信任顏色。不同的製造商使用不同的顏色方案。連接前，檢查標記、產品頁面或技術描述。

帶有單獨電源的詳細連接圖在實務部分：[連接伺服馬達](../06-practical-guides/03-connecting-servo.md)。

## 「伺服馬達」是什麼意思

在典型的位置業餘伺服馬達內部，有：

- 直流馬達；
- 齒輪箱；
- 位置感應器，通常是電位器；
- 控制主板；
- 輸出軸和臂。

外部控制器不直接管理馬達。它發送位置信號，伺服的內部電子設備自動轉動馬達，使軸到達所需角度。

所以伺服馬達與常規直流馬達不同：

- 直流馬達在通電時旋轉；
- 伺服試圖到達設定位置；
- 伺服在軸上有負載時即使在保持時也吸取電流；
- 伺服可以快速增加電流並在卡住時變熱。

## 位置和連續旋轉

最常見的類型是位置伺服馬達。你設定角度，例如 `0`、`90` 或 `180` 度。

連續旋轉伺服看起來相似但工作方式不同：控制信號不設定角度，而是旋轉的方向和速度。它不知道軸在哪裡。對於擋板或鎖，這樣的伺服通常不方便，因為沒有額外的感應器，你無法保證位置。

購買前，檢查描述所說的內容：

- `標準伺服馬達`、`位置伺服馬達`、`180°` - 通常是位置的；
- `連續旋轉`、`360°` - 通常連續旋轉，不定位到角度。

市集上的短語 `360° 伺服馬達` 有風險：有時它是連續旋轉伺服馬達，有時它只是擴展範圍。你需要檢查技術描述和具有實際測量的評論。

## 控制信號

典型的業餘伺服馬達由重複脈衝控制。

典型的準則：

- 週期約 `20 ms`；
- 脈衝約 `1 ms` - 範圍的一個邊緣；
- 脈衝約 `1.5 ms` - 中間；
- 脈衝約 `2 ms` - 範圍的另一個邊緣。

不同的伺服馬達有不同的實際限制。有些工作約 `500-2500 us`，其他人安全地只在較窄的範圍內。

所以極端位置無法盲目設定。首先檢查中間，然後小偏差，只有這樣才能擴大範圍。

## 電源和電流

信號線不為伺服馬達供電。它從電源線吸取馬達能量。

即使是小伺服馬達也可以在啟動、快速移動或機械停止時短暫吸取大電流。平均電流「在安靜演示中」不顯示最壞情況。

重要的參數：

- 工作電壓；
- 無負載電流；
- 有負載電流；
- 堵轉電流 - 軸被堵住時的電流；
- 保持轉矩或堵轉轉矩；
- 旋轉速度；
- 工作溫度。

如果技術描述列出堵轉電流，電源必須用該值和裕度選擇。如果未列出堵轉電流，你無法認為電源「用眼睛看起來是安全的」：對於真實設備，最好使用有裕度的電源並檢查負載下的電壓降。

對於一個小伺服馬達，主板的 5V 輸出有時會工作。但對於擋板、鎖或多個伺服馬達，你通常需要單獨的 5V/6V DC-DC 轉換器或電源。接地必須與控制器共用。

## 轉矩和機械

伺服馬達不僅按尺寸選擇。主要的機械參數是轉矩，通常以 `kg·cm` 或 `N·cm` 為單位。

粗略地：

- 槓桿越長，所需的轉矩越多；
- 擋板越重或機構越緊，所需的轉矩越多；
- 摩擦、不對齐和密封大大增加負載；
- 當在停止位置保持時，伺服馬達變熱並吸取電流。

例子：小輕擋板可能與微伺服馬達工作良好。密封上的擋板或帶彈簧的蓋可能需要較大的伺服馬達和金屬齒輪。

對於可靠的機械：

- 不要強迫伺服馬達持續對物理停止施加力；
- 限制韌體中的角度；
- 留下一個小的旅程裕度；
- 製作沒有不對齐的連接；
- 使用合適的臂長；
- 在真實外殼溫度下測試操作。

如果伺服馬達在末端位置嗡嗡作響，它通常表示負載、停止或錯誤的幾何形狀。

## 齒輪箱：塑膠或金屬

塑膠齒輪更便宜、更安靜，適合輕任務。但它們在碰撞、卡住和重負載下更快地斷裂。

金屬齒輪更強，但伺服馬達可能更大聲、更重且更昂貴。對於擋板、鎖和用戶可能意外接觸的機構，金屬齒輪箱通常很有意義。

但金屬齒輪不能替代好的機械。如果機構卡住，它可能損壞臂、外殼、支架或軸本身。

## 類比和數位伺服馬達

在簡單的專案中，類比業餘伺服馬達更常見。數位伺服馬達通常保持位置更牢固並反應更快，但可能吸取更多電流並在保持時更大聲。

對於烘乾機擋板或簡單的鎖，通常更重要的是：

- 足夠的轉矩；
- 正常的電源；
- 可靠的機械；
- 清晰的角度範圍；
- 工作溫度；
- 齒輪箱壽命。

「數位」不會自動使伺服馬達對設備很好。

## 購買前要檢查的事項

在購買伺服馬達之前，檢查：

- 位置或連續旋轉；
- 工作電壓；
- 需要的電流和如果列出堵轉電流；
- 轉矩；
- 旋轉速度；
- 角度範圍；
- 齒輪箱材料；
- 外殼尺寸；
- 連接器類型；
- 線長；
- 工作溫度；
- 技術描述或合理規格的可用性。

對於小旗，你可以使用微伺服馬達。對於密封上的擋板、鎖或暖室內的槓桿，最好不要選擇沒有規格的最便宜的伺服馬達。

## 常見錯誤

- 從 GPIO 為伺服馬達供電；
- 從弱主板 5V 腳位供電；
- 忘記與單獨電源的共同接地；
- 在不檢查的情況下信任線路顏色；
- 混淆位置伺服馬達和連續旋轉伺服馬達；
- 未考慮堵轉電流；
- 將伺服馬達放在機械停止處；
- 在機構只在狹窄範圍內安全移動時使用角度 `0` 或 `180`；
- 僅按尺寸選擇伺服馬達，不計算轉矩；
- 在可能發生碰撞或卡住的地方放置塑膠齒輪；
- 在加熱器附近無溫度檢查的情況下放置伺服馬達。

## 要點

伺服馬達是擋板、鎖和小機構的方便元件，但它需要正常的電源和仔細的機械。來自控制器的信號只設定位置，所有馬達電流通過電源線。

在使用之前，檢查伺服馬達類型、電壓、轉矩、電流、角度範圍和末端位置的機械行為。
