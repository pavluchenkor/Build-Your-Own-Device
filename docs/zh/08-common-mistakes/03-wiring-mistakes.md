# 连线错误

连线通常比电子本身更容易破坏设备。

接触不良、极性反向或端子薄弱可能看起来像固件、传感器或控制器错误。

## 症状

连线问题的典型迹象：

- 设备有时工作，然后不工作;
- 仅当移动电缆时才检测到电路板;
- 传感器显示乱码;
- 温度跳动;
- 风扇断断续续启动;
- USB 掉线;
- 端子发热;
- 导线变黑或发出气味;
- 模块在面包板上工作但在外壳中不工作;
- 关闭盖子后设备停止工作。

如果症状在移动导线时改变，首先检查连线。

## 极性反向

极性不能"按颜色"检查。

红色导线通常是正极，黑色导线通常是负极，但这不是保证。在 DIY 设备中，前一个构建者或你自己可能混淆了颜色。

连接前：

- 检查电路板标记;
- 检查模块引脚分配;
- 用万用表测量电压;
- 验证其中 `+` 和 `GND`;
- 如果引脚分配不清楚，不要连接模块。

极性反向可能会立即损坏电路板、传感器、风扇或 DC-DC。

## 无公共地

当一个模块单独供电，信号来自控制器时，需要公共地。

示例：

- 伺服带单独的 5V 电源;
- MOSFET 模块用于风扇;
- 4 针 PWM 风扇;
- HX711;
- RFID 模块;
- 外部传感器。

没有公共 `GND`，信号可能没有意义。设备可能无法响应、抖动或工作不稳定。

## 端子中的接触不良

端子可能看起来已夹紧，但导线握持不良。

原因：

- 导线没有完全插入;
- 绝缘被夹而不是导体;
- 绞合导线散开;
- 螺钉松动;
- 端子不适合电流;
- 导线对端子来说太细或太粗;
- 需要的地方没有引脚。

接触不良会导致加热。加热会恶化接触。这是一个危险的循环。

在短暂的负载测试后，检查端子和连接器是否发热。

## Dupont 不用于电力负载

Dupont 导线便于面包板和弱信号。

但它们不能被视为以下的正常电源连线：

- 加热器;
- 强大的风扇;
- LED 灯带;
- 电流大的伺服;
- 设备电源;
- 110-230V AC。

Dupont 可能握持不力、接触面积小，并在其不是为之设计的电流下发热。

对于电力部分，你需要合适的端子、连接器、导线横截面和应力释放。

## TX 和 RX

对于 UART，通常需要交叉连接：

- 一个设备的 `TX` 到另一个的 `RX`;
- 一个设备的 `RX` 到另一个的 `TX`;
- 公共 `GND`。

典型的错误：

- 连接 `TX` 到 `TX`;
- 连接 `RX` 到 `RX`;
- 忘记 `GND`;
- 选择了错误的速度;
- 逻辑电平不匹配：5V 和 3.3V。

如果 UART 无法工作，首先检查 `TX/RX/GND`，然后是速度和设置。

## I2C 和 SPI

对于 I2C：

- `SDA` 必须连到 `SDA`;
- `SCL` 必须连到 `SCL`;
- 需要公共 `GND`;
- 设备地址不能冲突;
- 导线必须很短。

对于 SPI：

- `MOSI`、`MISO`、`SCK`、`CS` 必须匹配引脚分配;
- 每个设备都有自己的 `CS`;
- 需要公共 `GND`;
- 长导线可能会破坏连接。

RFID RC522 经常让人困惑：电路板上的 `SDA` 引脚可能表示 SPI 的 `SS/CS`，而不是 I2C `SDA`。

## 主电源和信号导线

110-230V AC 导线、电力 DC 负载和弱信号不能随意铺设在一个束中。

问题：

- 干扰;
- 加热;
- 绝缘损伤;
- 接触主电源部分的风险;
- 困难的诊断;
- 用户危险。

主电源部分必须物理分离。低压传感器、UART/I2C/SPI 和热敏电阻导线最好与加热器电源导线分开铺设。

## 暴露的股线

端子外的暴露导线是一个坏信号。

它可以：

- 接触相邻的端子;
- 短接外壳;
- 进入盖子下方;
- 击中风扇;
- 在维护期间造成危险。

在端子中夹紧后，不应有长裸露的股线伸出。

## 检查什么

迷你检查清单：

1. 电源极性。
2. 公共 `GND`。
3. 引脚分配对应。
4. 端子质量。
5. 没有绝缘被夹而不是导体。
6. 没有暴露的股线。
7. 导线不紧张。
8. 盖子不会夹住电缆。
9. 电源和信号导线分离。
10. 连接器适合电流。
11. 设备在移动导线时不改变行为。

## 不要做什么

你不能：

- 在电源下改变导线;
- 在工作台上打开主电源部分;
- 为加热器使用 Dupont;
- 夹紧绞合导线使一些股线伸出;
- 在没有适当连接的情况下扭转电源导线;
- 忽视发热的端子;
- 认为"有时工作"是正常的。

## 关键要点

- 如果设备对导线移动有反应，这是连线问题。
- 极性用万用表检查，而不是按颜色。
- 公共 `GND` 对于大多数带单独电源的外部模块是必需的。
- Dupont 适合面包板和信号，但不适合电力负载。
- 主电源和低压导线必须分离。
- 发热的端子是停止的原因，而不是继续测试。
