# 自制耗材干燥机

本节帮助你设计并构建自己的耗材干燥机或 3D 打印机主动加热箱体。内容包括电子基础、控制器选择、加热器、风扇、传感器、外壳设计，以及第一次组装前值得排查的常见错误。

不需要预先具备电子经验。每篇文章只关注一个主题，并链接到相关材料。

## 内容

- `00-start-here/01-introduction.md` - 本节适合谁、如何阅读，以及为什么从简单内容逐步进入复杂内容。
- `01-electronics-basics/` - 电压、电流、功率、MOSFET、TRIAC 和 SSR。
- `02-controllers/` - ESP32、Arduino、RP2040、STM32、Klipper MCU 和通信接口。
- `03-common-components/` - 加热器、风扇、热敏电阻、LED 灯带、舵机、称重传感器、显示屏和 RFID/NFC。
- `04-thermal-physics-and-materials/` - 热、导热、气体、材料、可燃性和安全。
- `05-tools/` - 万用表、USB-TTL、焊接、压接、ST-Link 和示波器。
- `06-practical-guides/` - 风扇、热敏电阻、舵机、称重传感器和 RFID 读卡器的实际连接。
- `07-3d-printing/` - 打印件、STL、PETG/ABS/ASA、耐热材料和外壳设计。
- `08-common-mistakes/` - 电源、接线、控制器、加热器、SSR 的常见错误和诊断清单。
