# 固态继电器

固态继电器（SSR）是没有机械接点的继电器。您从控制器向SSR输入应用弱控制信号，SSR输出打开或关闭负荷。

在3D打印机的简单设备中，SSR通常用于商用加热器：腔室、烘干机、工作台或单独的加热模块。它是从低电压电子设备控制`110-230V AC`负荷的便利方式，但不是使商用电源安全的方式。

如果项目具有`110-230V AC`，电力部分必须在外壳、保险丝、正常端子、绝缘、电缆应变释放和电气安全理解中组装。

## SSR与普通继电器有何区别

普通电磁继电器发出咔哒声，因为接点在内部物理移动。继电器线圈需要电力，通常需要晶体管驱动器、保护二极管，接点可能会产生火花、振动和磨损。

SSR使用半导体切换负荷。因此，它没有点击声、没有机械接点磨损，更适合频繁的加热器开/关周期。

但SSR不是「没有缺点的继电器」。

SSR有自己的限制：

- 升温；
- 通常需要散热片；
- 在关闭状态可能有小漏电流；
- 比适当选择的接触器更差地容忍过载和尖峰；
- 可能在「开启」状态下失效；
- 必须为AC或DC负荷选择；
- 不取代保险丝、外壳和紧急热保护。

对于不频繁的电源周期，普通继电器或接触器可能更合适。对于阻抗性加热器的频繁控制，SSR通常更实用。

## AC SSR内部是什么

AC SSR通常包含：

- 控制信号输入电路；
- 光隔离；
- 触发电路；
- 电力TRIAC或晶闸管对；
- 阻尼器电路或其他尖峰保护；
- 负荷的电源端子。

简单来说，它是外壳内现成的TRIAC电路。因此，SSR在您不想自己计算光耦合器TRIAC、TRIAC、阻尼器、电路板间距和商用部分的地方便利。

现成的外壳不消除验证的需要。特别是如果SSR便宜、没有技术规格或外壳上有怀疑的高电流额定。

## AC SSR和DC SSR

SSR必须根据负荷类型选择：

- **AC SSR** - 用于交流，例如商用加热器`110-230V AC`；
- **DC SSR** - 用于直流，例如`12V`或`24V` DC负荷。

这些是不同的设备。AC SSR不能自动放在`24V` DC加热器上：它可能不会关闭。DC SSR不能认为适合`230V AC`：它可能危险且不适合这样的电路。

您需要检查不仅是`AC`或`DC`标签，还有输出电压范围。

标记示例：

```text
Input: 3-32V DC
Output: 24-380V AC
```

这意味着：

- 输入由低电压DC信号控制；
- 输出在指定范围内切换AC负荷；
- 您无需通过SSR从输入侧向负荷供电。

购买前，检查`Input`、`Output`、`Load voltage`、`Load current`行和制造商的接线图。

## 典型接线图

SSR通常放在负荷电源线的断裂处。控制器仅连接到SSR输入，而商用电路通过SSR输出。

重要点：

- SSR输入和SSR输出是设备的不同侧面；
- 低电压侧不应连接到商用侧；
- SSR放在负荷电源线的断裂处，通常`Line`；
- 保护接地`PE`不通过SSR断裂；
- 保险丝必须保护配线和负荷；
- 加热器需要独立热保护；
- 整个商用部分必须关闭以防触摸。

SSR不被视为服务断开。对于维护，您需要一种物理方式来切断电源：开关、断路器、连接器或其他标准电路断路器。实际上，可能有不同的电路方案，根据当地规则、电源类型、保护接地和外壳。如果您不确定，合格的人应验证电路。

## 零点、随机启动和控制

AC SSR具有不同的启动方法。

**零点SSR**在商用电压零点附近打开负荷。这是阻抗性加热器简单开/关的好选项：减少噪音和更柔和的切换。

**随机启动SSR**在施加控制信号后几乎立即打开输出。此类型用于需要不同逻辑、相位控制或特定负荷要求的地方。

对于腔室、烘干机或简单加热器，通常不需要快速调光控制。通常缓慢控制就足够了：例如，开启加热器数秒，而不是每秒数百次抖动。

并非所有SSR都适合相位控制。如果您特别需要相位电源调节器，这是一个单独的设备类型和一个单独的主题（噪音、加热和负荷要求）。

## 漏电流

SSR即使在「关闭」时也可以传递小电流。这称为漏电流。

对于强大的加热器，此类电流通常不会产生显著的加热，但对于小灯、LED驱动器、电源或非常小的负荷，它可能很显著：指示灯可能弱光，电源输入可能表现异常。

因此，SSR不应被视为理想的电路断路器。在第一次加热器启动之前，验证当除去控制信号时负荷不加热。最好先用安全的小负荷、灯或万用表测试SSR输出，而不是立即用主加热器。

对于维护、紧急关闭和完全隔离，您需要开关、断路器、保险丝、连接器或其他物理方式来切断电源。

## 加热和散热片

SSR在运行中升温。在开启状态，电力元件通过有电压降，这意味着生成热量。

您需要检查：

- 负荷电流；
- 实际温度下SSR的最大电流；
- 输出电压降；
- 散热片要求；
- 外壳内温度；
- 散热片方向和气流；
- SSR和散热片之间的热接触质量；
- 测试后端子和电线的温度。

`25A`或`40A`标签并不意味着SSR将在加热器旁边的密闭外壳中在没有散热片的情况下承受这样的电流。制造商通常在特定冷却条件下指定电流。

简单项目的实用规则：不要仅为负荷电流精确选择SSR。计划余量、使用散热片、阅读技术规格和验证实际外壳中的温度。`50%`余量是初始估计的下限，不是任何安装的保证。

## SSR不保护加热器

SSR是电源开关，不是安全系统。

加热器需要独立的层：

- 配线和负荷的保险丝或断路器；
- 正确的温度传感器；
- 软件温度限制；
- 固件中的加热检查；
- 独立恒温器、热保险丝或双金属开关；
- 由能承受实际温度的材料制成的外壳；
- 在观察下进行首次测试。

重要故障模式：SSR可能故障并保持开启。因此，紧急热保护必须能够独立于控制器和SSR切断加热器电源。

## 哪些负荷合适

SSR最容易用于电阻AC负荷：

- 加热器；
- 硅胶加热垫；
- 白炽灯；
- 没有内置电子设备的简单热负荷。

谨慎使用：

- 马达；
- AC风扇；
- 变压器；
- 螺线管；
- 电源；
- 电子驱动器；
- 高浪涌电流负荷。

归纳和电子负荷可能需要不同类型的SSR、阻尼器、变阻器、接触器或单独的电路。您不能仅通过「40A」标签选择SSR。

## 购买前检查的事项

购买SSR之前，检查：

- 负荷AC或DC；
- 负荷电压；
- 负荷电流和电力；
- 控制输入电压；
- 与控制器的输入兼容性：`3.3V`、`5V`、`12V`或其他级别；
- 启动类型：零点或随机；
- 所需冷却下的最大电流；
- 是否需要散热片；
- 是否有技术规格；
- 是否有正常接线图；
- 端子和绝缘距离；
- 制造商质量；
- 保险丝放置的位置；
- 独立热保护将在哪里。

如果没有文档，SSR必须控制商用加热器，这是个糟糕的选择。

## 常见错误

- 混淆SSR输入和输出；
- 购买DC SSR而不是AC SSR或反之；
- 未检查输出电压范围；
- 将AC SSR连接到DC加热器并惊讶它不关闭；
- 为负荷电流选择SSR；
- 在没有散热片的情况下安装SSR；
- 在密闭、热外壳中安装SSR；
- 未考虑漏电流；
- 将SSR用作紧急关闭的唯一方式；
- 忘记保险丝；
- 未安装独立热保护；
- 保持商用端子可访问；
- 在不理解SSR类型和负荷的情况下使用快速PWM控制SSR。

## 主要点

SSR便于频繁安静的负荷控制，特别是商用阻抗性加热器。但SSR必须为负荷类型、电压、电流、启动方法和热动作点选择。

对于`110-230V AC`负荷，SSR不消除电气安全。您需要外壳、保险丝、正常配线、必要时散热片和独立加热器热保护。
