# Postavte si vlastní sušičku filamentu

Tato sekce pomáhá navrhnout a postavit vlastní sušičku filamentu nebo aktivní vyhřívanou komoru pro 3D tiskárnu. Pokrývá základy elektroniky, výběr řídicí desky, topná tělesa, ventilátory, senzory, návrh krytu a časté chyby, které je vhodné odstranit ještě před první stavbou.

Předchozí zkušenosti s elektronikou nejsou nutné. Každý článek se věnuje jednomu tématu a odkazuje na související materiály.

## Obsah

- `00-start-here/01-introduction.md` - komu je sekce určena a jak ji číst.
- `01-electronics-basics/` - napětí, proud, výkon, MOSFET, TRIAC a SSR.
- `02-controllers/` - ESP32, Arduino, RP2040, STM32, Klipper MCU a komunikační rozhraní.
- `03-common-components/` - topná tělesa, ventilátory, termistory, LED pásky, serva, váhové senzory, displeje a RFID/NFC.
- `04-thermal-physics-and-materials/` - teplo, vedení tepla, proudění vzduchu, materiály, hořlavost a bezpečnost.
- `05-tools/` - multimetr, USB-TTL, pájení, krimpování, ST-Link a osciloskop.
- `06-practical-guides/` - praktické zapojení ventilátoru, termistoru, serva, váhového senzoru a RFID čtečky.
- `07-3d-printing/` - tištěné díly, STL, PETG/ABS/ASA, tepelně odolné materiály a návrh krytu.
- `08-common-mistakes/` - typické chyby napájení, zapojení, řídicí desky, topení, SSR a diagnostický checklist.
