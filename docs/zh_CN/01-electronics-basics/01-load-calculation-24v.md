# 电流、电压与负荷电力

在连接加热器、风扇、LED灯带、伺服驱动器或其他模块之前，您需要理解三件事：

- 电压；
- 电流；
- 电力。

如果没有这个，很容易购买错误的电源、过热电线、熔化连接器、烧毁MOSFET模块或将负荷连接到控制器，使其不稳定工作。

## 参数在哪里找

电压、电流和电力通常可在以下位置找到：

- 元件外壳上；
- 电源标签上；
- 产品页面上；
- 技术规格中；
- 手册中；
- 电路图或引脚排列图中。

如果未指定参数，这不是小问题。这是停下来弄清楚您要连接什么的理由。

对于3D打印机外设中的元件，典型的参数如下：

- 风扇：`24V 0.2A`；
- 加热器：`24V 100W`；
- LED灯带：`24V 9.6W/m`；
- 伺服驱动器：`5V`，电流取决于负荷；
- 控制器板：每个输出的最大电流单独指定。

## 电压必须匹配

负荷是为特定电压设计的。

例子：

- 风扇可以是`5V`、`12V`或`24V`；
- LED灯带可以是`5V`、`12V`或`24V`；
- 伺服驱动器通常额定为`5V`或`6V`；
- 加热器可以是`12V`、`24V`或`110-230V AC`。

如果您将`24V`风扇连接到`12V`，它可能无法启动或工作不力。如果您将`12V`风扇连接到`24V`，它可能很快失效。

主要规则：

**电源电压必须与负荷电压匹配。**

不要仅因为连接器在物理上适配就将设备连接到更高电压。

## 电力显示负荷大小

电力显示负荷消耗或转化为工作、热、光或运动的能量。

电力以瓦特测量：`W`。

例子：

- `24V 5W` - 小负荷；
- `24V 24W` - 约`1A`；
- `24V 120W` - 已约`5A`；
- `24V 240W` - 约`10A`。

加热器通常消耗大量电力。风扇消耗较少，但可能有高浪涌电流。LED灯带如果很短可能是小负荷，或者如果很长且很亮可能是重负荷。

## 电流对电线和电源元件加载

电流显示流过电线、端子、连接器和电源元件的电量。

电流经常造成实际问题：

- 电线发热；
- 端子变暗；
- 连接器熔化；
- MOSFET过热；
- 电源不足；
- 负荷打开时设备重新启动；
- 保险丝熔断不是巧合，而是由于实际过载或错误。

因此，仅知道电压是不够的。您需要计算电流。

## 计算公式

对于大多数简单计算，您需要电力公式：

```text
P = U * I
```

其中：

- `P` - 瓦特电力`W`；
- `U` - 伏特电压`V`；
- `I` - 安培电流`A`。

要找到电流：

```text
I = P / U
```

此公式不是为了考试。需要理解电源、电线、端子、MOSFET模块、继电器、SSR或电路板输出是否能承受它。

## 24V的快速表

在3D打印机和外设中，`24V`很常见。为了快速评估，记住以下有用：

| 电力 | 24V时的电流 |
|---:|---:|
| `12W` | `0.5A` |
| `24W` | `1A` |
| `48W` | `2A` |
| `96W` | `4A` |
| `120W` | `5A` |
| `240W` | `10A` |
| `300W` | `12.5A` |

这些是近似值，但对于电源、电线和电源开关的首次选择非常有用。

## 示例：24V 100W加热器

您有一个加热器：

```text
24V 100W
```

计算电流：

```text
I = 100W / 24V = 4.17A
```

这意味着以下必须能承受超过`4.17A`：

- 电源；
- 电线；
- 端子；
- 连接器；
- MOSFET或SSR；
- 保险丝和保险丝架；
- 电路板迹线（如果加热器连接到电路板）。

如果电源额定为`24V 5A`，形式上接近负荷，但几乎没有余量。对于真实设备，最好选择更大的。

## 示例：多个负荷

假设`24V`设备有：

- 加热器`100W`；
- 风扇`24V 0.2A`；
- LED灯带`24V 1A`；
- 另一个风扇`24V 0.15A`。

计算加热器：

```text
100W / 24V = 4.17A
```

将它们相加：

```text
4.17A + 0.2A + 1A + 0.15A = 5.52A
```

最小电源"紧凑型"将约为`24V 6A`，但这对于长期运作是个糟糕的选择。使用`50%`余量：

```text
5.52A * 1.5 = 8.28A
```

实际上，如果外壳、冷却和安全允许，您应该查看`24V 9A`、`24V 10A`或更大电源。

## 余量是必须的

电源、布线、端子和电源模块不能根据计算电流精确选择。

对于本指南，粗略第一次评估的简单规则：

**计划至少`50%`的余量**，除非特定元件的文档要求更多。这不是普遍保证，而是开始估计。最终选择根据技术规格、外壳内温度、冷却、降额和端子/电线的实际加热进行。

需要余量的原因：

- 电源升温；
- 外壳内的温度可能高于室温；
- 风扇和马达有浪涌电流；
- 接触点老化并松动；
- 端子有电流和温度限制；
- SSR和MOSFET产生热量；
- 电源可能有降额 - 在高温或通风不良时最大功率降低。

工业电源通常在技术规格中有一条降额曲线——随温度升高最大功率降低的曲线。降额意味着在高温或通风不良时，制造商降低最大允许功率。因此，电源上的`240W`标签并不总是意味着在密闭热外壳中能安全供应`240W`。

## 弱点可能不是电源

即使电源强大，电路可能在其他地方较弱。

您需要检查整个电路：

- 电源输出；
- 电线；
- 端子块；
- 连接器；
- 保险丝；
- MOSFET模块；
- 继电器或SSR；
- 电路板迹线；
- 负荷本身。

例如，电源可以承受`10A`，但小连接器或劣质螺丝端子在较低电流下可能已经升温。这对加热器和LED灯带特别重要。

## 什么是电源开关

电源开关是一种受控开关。

控制器不直接为重负荷供电。它给出弱控制信号，电源开关打开或关闭负荷电流。

例子：

- 用于`12V`/`24V` DC负荷的MOSFET模块；
- 继电器；
- SSR；
- 现成的负荷驱动器；
- 电路板的标准输出（如果为所需负荷额定）。

对于加热器、风扇、LED灯带和马达，规则几乎总是适用：

**控制器的GPIO不向负荷供电。GPIO仅控制。**

## 关于欧姆定律的一点

欧姆定律将电压、电流和电阻相关联：

```text
U = I * R
```

对于本文，简单的想法很重要：如果您向负荷施加电压，电流将通过它流动。流动多少电流取决于负荷本身。

但并非所有负荷都表现相同：

- 加热器接近电阻负荷；
- 风扇和马达有浪涌电流；
- 伺服驱动器在阻塞时电流急剧增加；
- LED灯带按长度和亮度消耗电流；
- 电子模块打开时可能有瞬态电流。

因此，对于真实设备最好从技术规格获取数据或用万用表/实验室电源测量电流（如果安全）。

## 连接前检查的内容

在连接负荷之前，回答：

1. 负荷的额定电压是多少？
2. 是DC负荷还是AC负荷？
3. 指定什么电力或电流？
4. 您从公式`I = P / U`得到多少电流？
5. 同一电源上还有哪些其他负荷？
6. 至少有`50%`的余量吗？
7. 电线、端子、连接器和电路板能承受吗？
8. 什么控制负荷：MOSFET、继电器、SSR或标准输出？
9. 需要保险丝吗？
10. 如果发生短路、马达卡住或风扇故障会怎样？

如果这是加热器或商用电源`110-230V AC`，安全要求更高。商用段不能通过猜测组装：您需要合适的外壳、保险丝、绝缘、保护接地`PE`、电线应力释放和合格人员的验证。

## 主要点

- 电源电压必须与负荷电压匹配。
- 电力显示负荷的大小。
- 电流显示对电线、端子、连接器和电源元件的负荷。
- 基本公式：`I = P / U`。
- 在`24V`系统中`24W`约`1A`，`120W`约`5A`，`240W`约`10A`。
- 一个电源上所有负荷的电流相加。
- 粗略第一次估计需要至少`50%`余量；精确选择根据技术规格、温度、冷却和降额进行。
- 弱点可能不是电源，而是端子、连接器、电线、MOSFET或电路板迹线。
- 控制器的GPIO不向重负荷供电，只控制电源开关。
