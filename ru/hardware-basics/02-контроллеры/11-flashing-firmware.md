# Прошивка контроллера

Прошивка - это программа, которая записывается в микроконтроллер.

Конфигурация - это настройки, которые говорят прошивке, как работать.

Это разные вещи. Прошивку записывают в контроллер. Конфигурация Клипера обычно лежит на хосте в файле `printer.cfg`.

## Общий маршрут

Обычно порядок такой:

1. Понять, какая плата используется.
2. Найти точный микроконтроллер.
3. Найти документацию и pinout.
4. Выбрать тип прошивки: автономная или Клипер MCU.
5. Собрать или скачать файл прошивки.
6. Перевести плату в режим прошивки.
7. Записать прошивку.
8. Проверить, что устройство появилось в системе.

## RP2040

Для Raspberry Pi Pico и многих RP2040-плат часто используется режим BOOTSEL и файл UF2.

Обычно это выглядит так:

1. Зажать `BOOTSEL`.
2. Подключить USB.
3. Плата появится как флешка.
4. Скопировать UF2-файл.
5. Плата перезагрузится.

Это один из самых простых способов прошивки.

## STM32

STM32 может прошиваться по-разному:

- через DFU по USB;
- через SD-карту, если это 3D-принтерная плата;
- через ST-Link по SWD;
- через bootloader конкретной платы.

Главная сложность STM32 - не сам чип, а разнообразие плат и способов входа в режим прошивки.

## Arduino/AVR

Arduino Uno/Nano обычно прошиваются через загрузчик и USB-UART.

Это удобно для учебных скетчей, но для Клипер-подобного нового устройства это не лучший основной путь.

## Типовые ошибки

Частые ошибки:

- USB-кабель только для зарядки, без данных;
- выбрана не та плата;
- выбран не тот микроконтроллер в сборке;
- плата не переведена в режим прошивки;
- прошивка записана, но не туда;
- после прошивки не проверили serial/by-id;
- одновременно подключили питание с двух сторон.

## Главное

- Прошивка и конфигурация - не одно и то же.
- Для RP2040 часто проще всего BOOTSEL и UF2.
- Для STM32 нужно смотреть конкретную плату и способ прошивки.
- Для Клипера важно найти стабильный путь устройства в системе, обычно `/dev/serial/by-id/...`.
- Перед прошивкой нужно читать документацию платы.

## Заметки для разработки

- Использовать русский термин "прошивка", английский `firmware` можно дать в скобках при первом расширении статьи.
- Для Клипера объяснить `make menuconfig`, но не в первой короткой канве.
- Обязательно упомянуть USB data cable.
- Для STM32 позже раскрыть DFU, SWD, ST-Link.
- Для RP2040 раскрыть BOOTSEL и UF2.
