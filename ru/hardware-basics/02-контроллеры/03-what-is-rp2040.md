# RP2040

RP2040 - это микроконтроллер Raspberry Pi. Самая известная плата на нём - Raspberry Pi Pico.

Это один из самых удобных вариантов для самодельной периферии: он дешёвый, быстрый, хорошо документирован и нормально подходит для работы как MCU в Клипер.

## Почему RP2040 удобен

Плюсы RP2040:

- низкая цена;
- много GPIO;
- 3.3V логика;
- удобная прошивка через USB;
- режим BOOTSEL;
- можно использовать в собственных прошивках;
- можно использовать как дополнительную MCU в Клипер.

Для iDryer-подобного устройства RP2040 хорош, если нужно сделать отдельную плату, которая будет работать рядом с основной платой принтера или как часть Клипер-системы.

## Цена как ориентир

Оригинальная Raspberry Pi Pico обычно относится к очень дешёвым отладочным платам: ориентир по цене - примерно от `$4`.

Обычные платы на RP2040 и Pico-совместимые клоны часто встречаются примерно в диапазоне `$4-10`. Версии с Wi-Fi, распаянными пинами или дополнительными разъёмами обычно стоят дороже.

Это делает RP2040 очень удобной отправной точкой: цена низкая, а возможностей достаточно много.

## RP2040 и Клипер

RP2040 хорошо подходит для Клипер MCU.

Идея такая:

- Клипер хост работает на Linux-устройстве;
- RP2040 прошивается firmware для Клипера;
- в конфигурации появляется `[mcu]` или дополнительная MCU;
- пины RP2040 можно использовать для вентиляторов, датчиков, выходов, PWM и другой периферии.

Это удобно для расширения принтера или iDryer-периферии без написания полностью собственной системы управления.

## BOOTSEL и UF2

У Raspberry Pi Pico есть удобный режим прошивки:

1. Зажать кнопку `BOOTSEL`.
2. Подключить USB.
3. Плата появится как флешка.
4. Скопировать файл прошивки.

Такой способ проще, чем многие STM32-сценарии с DFU, ST-Link или SD-картой.

## Главное

- RP2040 - очень хороший кандидат для нового самодельного контроллера.
- Raspberry Pi Pico дешёвый и доступный.
- RP2040 подходит для Клипер MCU.
- Логика GPIO - 3.3V.
- Для простой периферии RP2040 часто понятнее, чем STM32.

---

## Заметки для разработки

- Русский термин: микроконтроллер RP2040. Английский термин тот же: `RP2040`.
- Обязательно объяснить Raspberry Pi Pico как самую понятную плату.
- Указать BOOTSEL и UF2.
- Ориентир цены: `$4-10`.
- Подчеркнуть: хорошая стартовая точка для Клипер MCU.
