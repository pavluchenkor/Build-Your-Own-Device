# UART

UART - это простой последовательный интерфейс передачи данных между устройствами.

Расшифровка: `Universal Asynchronous Receiver/Transmitter`. По смыслу это узел, который умеет передавать и принимать данные по последовательной линии.

В документации обычно говорят проще: UART-интерфейс, UART-порт или просто UART.

## Для чего нужен UART

UART нужен, чтобы два устройства могли обмениваться данными.

Например:

- контроллер общается с другим контроллером;
- плата передаёт логи в компьютер;
- компьютер прошивает плату через адаптер;
- плата 3D-принтера общается с некоторыми модулями;
- контроллер общается с драйвером мотора, если драйвер поддерживает UART.

## UART в 3D-принтерах

В 3D-принтерах UART встречается часто.

Через UART могут работать:

- отладочные сообщения;
- прошивка некоторых плат;
- связь с внешними модулями;
- управление некоторыми драйверами шаговых моторов;
- связь между платой и хостом в отдельных сценариях.

Например, драйверы шаговых моторов семейства TMC могут использовать UART для настройки тока, режима работы и диагностики. Это не значит, что мотор "управляется UART напрямую". Мотором всё равно управляют сигналы шаг/направление, а UART используется для настройки и обмена служебными данными.

## TX, RX и GND

Для первого понимания достаточно трёх линий:

- `TX` - передача данных;
- `RX` - приём данных;
- `GND` - общий минус.

TX одного устройства подключают к RX другого:

```text
TX -> RX
RX <- TX
GND -> GND
```

Самая частая ошибка - соединить TX с TX и RX с RX.

## Скорость и настройки

У UART есть скорость передачи, например `115200`.

Если два устройства настроены на разную скорость, они не поймут друг друга.

В документации также можно встретить настройки вроде `8N1`. На начальном этапе достаточно знать, что это параметры формата передачи, и они должны совпадать на двух сторонах.

## 3.3V и 5V

UART - это не только TX/RX. Нужно ещё понимать уровни логики.

ESP32, RP2040 и STM32 обычно используют 3.3V логику. Arduino Uno/Nano часто работает с 5V логикой.

Если подать 5V UART-сигнал на вход 3.3V микроконтроллера, можно повредить плату.

## Главное

- UART - это простой интерфейс передачи данных между устройствами.
- У UART есть линии TX, RX и GND.
- TX подключают к RX, а GND должен быть общим.
- Скорость передачи должна совпадать на двух сторонах.
- Уровни 3.3V и 5V нельзя путать.
- USB-UART адаптер - это способ подключить UART к компьютеру через USB.

## Заметки для разработки

- Не называть UART "шиной" без оговорки. Для простоты можно говорить "интерфейс передачи данных".
- Объяснить TMC-драйверы аккуратно: UART используется для настройки/диагностики, а не как единственный способ физического вращения мотора.
