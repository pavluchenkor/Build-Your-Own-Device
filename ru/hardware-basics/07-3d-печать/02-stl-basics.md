# STL Basics

Что должен содержать файл:

- что такое STL простыми словами;
- почему STL - это только геометрия, а не инструкция по сборке;
- почему STL не содержит материал, ориентацию печати, прочность и настройки;
- почему одна и та же деталь может быть прочной или слабой в зависимости от ориентации;
- что ещё нужно кроме STL:
  - список материалов;
  - ориентация печати;
  - поддержка;
  - заполнение;
  - стенки;
  - крепёж;
  - предупреждения по температуре.

Практический смысл:

- пользователь должен понять, что скачать STL недостаточно;
- для деталей рядом с нагревом нужно знать материал и условия работы;
- для силовых креплений важно направление слоёв.
