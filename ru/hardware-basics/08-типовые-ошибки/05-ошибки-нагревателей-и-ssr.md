# Ошибки нагревателей и SSR

Что должен содержать файл:

- SSR выбран не под тот тип нагрузки: AC вместо DC или DC вместо AC;
- SSR стоит без радиатора;
- мощность нагревателя не посчитана;
- нет предохранителя;
- нет заземления корпуса;
- термодатчик плохо закреплён;
- силовая часть 220V собрана на слабых клеммах;
- MOSFET используют для 220V AC.

Симптомы:

- SSR греется;
- нагреватель не выключается;
- температура растёт неадекватно;
- клемма потемнела;
- автомат выбивает;
- устройство опасно трогать.

Важно:

- этот файл должен быть жёстким по безопасности;
- если пользователь не понимает 220V, лучше остановиться и попросить помощи специалиста.
