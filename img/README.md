# Images

Общая папка для изображений, схем и иллюстраций раздела `Build-Your-Own-Device`.

Изображения лежат отдельно от языковых версий, чтобы `ru/` и `en/` могли ссылаться на одни и те же файлы.

Структура повторяет основные разделы:

- `00-start-here/`
- `01-electronics-basics/`
- `02-controllers/`
- `03-common-components/`
- `04-thermal-physics-and-materials/`
- `05-tools/`
- `06-practical-guides/`
- `07-3d-printing/`
- `08-common-mistakes/`

Рекомендации по именам:

- использовать английские имена файлов;
- писать маленькими буквами;
- разделять слова дефисами;
- добавлять номер, если изображение относится к конкретной статье.

Примеры:

- `01-electronics-basics/01-load-current-24v-formula.png`
- `01-electronics-basics/02-mosfet-low-side-wiring.png`
- `03-common-components/03-fan-2pin-3pin-4pin.png`
- `04-thermal-physics-and-materials/04-heater-airflow.png`
- `06-practical-guides/01-connect-fan-wiring.png`

Форматы:

- `svg` - для простых схем и диаграмм;
- `png` - для скриншотов и растровых иллюстраций;
- `jpg` - для фотографий;
- `webp` - если нужно уменьшить размер без заметной потери качества.
